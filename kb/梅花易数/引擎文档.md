# 梅花易数引擎 v1 · 引擎文档

> 文件：`static/js/meihua-engine.js` | 流派：邵雍·先天易学 | 全局：`MeihuaEngine`

## 一、概述

梅花易数引擎，基于**邵雍先天易学**体系，采用**体用生克**分析法。纯前端算法，零 API 调用。支持数字起卦和日期起卦两种方式，自动计算本卦、互卦、变卦，并生成体用生克解读。

## 二、核心算法

### 2.1 起卦

- **数字起卦**：上卦数 ÷ 8 取余，下卦数 ÷ 8 取余，动爻数 ÷ 6 取余
- **日期起卦**：年数为上卦，月数为下卦，日数为动爻
- **余数0 → 8**（坤卦），**余数0 → 6**（上爻动）

### 2.2 八卦基础

| 索引 | 卦名 | 符号 | 五行 | 阴阳 | 爻象 |
|------|------|------|------|------|------|
| 1 | 乾 | ☰ | 金 | 阳 | 111 |
| 2 | 兑 | ☱ | 金 | 阴 | 110 |
| 3 | 离 | ☲ | 火 | 阴 | 101 |
| 4 | 震 | ☳ | 木 | 阳 | 100 |
| 5 | 巽 | ☴ | 木 | 阴 | 011 |
| 6 | 坎 | ☵ | 水 | 阳 | 010 |
| 7 | 艮 | ☶ | 土 | 阳 | 001 |
| 8 | 坤 | ☷ | 土 | 阴 | 000 |

### 2.3 互卦

互卦下卦 = 本卦第2-4爻，互卦上卦 = 本卦第3-5爻

### 2.4 变卦

动爻处阴阳互变，动爻在上卦则上卦为用，在下卦则下卦为用。

### 2.5 体用生克

以体卦为"我"，用卦为"事"，判断五行生克关系：

| 关系 | 等级 | 说明 |
|------|------|------|
| 用生体 | 4（大吉） | 用卦之气滋养体卦，万事顺遂 |
| 体用比和 | 3（中吉） | 五行相同，相互扶持 |
| 体生用 | 2（小吉） | 虽有付出，但可积德结缘 |
| 体克用 | 1（凶） | 虽能成事，但耗费心力 |
| 用克体 | 0（大凶） | 外力压制，宜守不宜攻 |

## 三、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `divine(params)` | `{ method, upper, lower, moving }` | 完整卦象结果 | 起卦主方法 |
| `BAGUA` | 无 | 八卦基础数据 | 静态属性 |
| `GUA64` | 无 | 64卦映射表 | 静态属性 |
| `WANWU_LEIXIANG` | 无 | 万物类象 | 静态属性 |

### divine 返回结构
```javascript
{
  original_gua: { name, shang_gua, xia_gua },

  wanwu_leixiang: { 体卦: {...}, 用卦: {...} },
  interpretation: '...'
}
```

## 四、万物类象

每个卦有完整的类象映射：
- **方位**：乾西北/兑西/离南/震东/巽东南/坎北/艮东北/坤西南
- **人事**：君父/少女/中女/长男/长女/中男/少男/母
- **身体**：首/口/目/足/股/耳/手/腹
- **颜色**：金白/白/赤/青绿/青绿/黑/黄/黄
- **季节**：秋冬/秋/夏/春/春夏/冬/冬春/夏秋

## 五、64卦解读

内置 ~60 条卦象解读速查表，覆盖常用卦的卦辞和象意。
