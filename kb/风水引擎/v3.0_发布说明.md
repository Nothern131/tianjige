# 风水引擎 v3.0 发布说明（2026-07-29）

## 概述
v3.0 在 v2.0 玄空飞星排盘基础上，新增**拼户型建造器**功能，支持多网格尺寸户型拼建、房间放置、实时风水排盘联动，解决用户反馈"3×3网格无法满足复杂户型"的问题。

## 问题背景

- 用户反馈：*"这一块格子可以多一点吗，户型有时候很复杂，或者再旁边放一些选项，比方说4×3，现在是3×3，4×4等"*
- 原设计局限：仅支持固定3×3网格（9个宫位），无法满足复杂户型需求
- 交互冲突：罗盘Canvas的 `pointer-events:auto` 拦截了网格单元格的点击事件

## v3.0 新增功能

### 1. 多网格尺寸支持

**支持5种尺寸**：3×3、4×3、4×4、5×4、5×5

**技术实现**：
- **CSS变量驱动**：`--grid-cols` / `--grid-rows` 两个变量控制网格行列数
- **动态网格生成**：`regenerateGrid(cols, rows)` 函数重建网格
- **宫殿映射算法**：`(col*3/cols, row*3/rows)` 映射到九宫格，保持宫殿分布逻辑一致

### 2. 拼户型建造器

**9种房间类型**：客厅、主卧、次卧、厨房、餐厅、卫生间、书房、阳台、玄关

**交互功能**：
- 点击放置房间
- 橡皮擦清除单格
- 随机布局
- 清空所有
- 实时联动风水排盘

### 3. 罗盘交互重构

**问题**：罗盘Canvas拦截网格点击

**方案**：
1. `pointer-events:none` 使罗盘仅作为视觉元素
2. 旋转逻辑迁移到 `gridWrapper`
3. 距离判断：外环（42%~51%半径）→ 旋转；网格（0~38%半径）→ 点击
4. 移除 `overflow: hidden`，支持纵向滚动

### 4. 布局优化

- 网格选择器移至 `grid-container` 内部，Canvas上方居中
- `.grid-container` 改为 `flex-direction: column` 纵向排列
- 网格选择器 `justify-content: center`，`margin-bottom: 10px`

## 函数变更概览

| 函数 | 功能 |
|------|------|
| `regenerateGrid(cols, rows)` | 动态重建网格，支持不同尺寸 |
| `randomizeGrid()` | 根据当前网格大小随机布局 |
| `clearAllRooms()` | 清空所有房间 |
| `updateCompassAndFengShui()` | 实时联动风水排盘 |
| 罗盘事件监听 | 从 `compassCanvas` 迁移至 `gridWrapper` |

## 技术要点

- **CSS变量**：动态控制网格布局，无需重新计算DOM结构
- **宫殿映射**：不同尺寸网格下，确保九宫格分布逻辑一致（中宫居中、四角对应等）
- **事件分离**：pointer-events + 距离判断，实现罗盘旋转与网格点击互不干扰
- **实时联动**：每次房间放置/变动 → 触发 `updateCompassAndFengShui()` → 重新排盘评估
