# 风水引擎 · 技术文档

> 版本：v3.0 | 文件：`static/js/fengshui-engine.js` | 类别：时空类 · 独立板块
> 体系参考：玄空飞星 · 三元九运 · 杨筠松峦头派 · 赖布衣理气派 · 蒋大鸿玄空派

## 一、概述

风水引擎实现玄空飞星风水排盘，支持二十四山坐向选择、三元九运判定、运盘/山星/向星/年星飞泊、九宫吉凶评估。附带拼户型建造器（9种房间类型+多网格尺寸）和户型图上传功能。

## 二、核心算法

### 2.1 二十四山

```
壬 子 癸 | 丑 艮 寅 | 甲 卯 乙 | 辰 巽 巳 | 丙 午 丁 | 未 坤 申 | 庚 酉 辛 | 戌 乾 亥
```

每山包含：八卦归属、三元（天元/人元/地元）、阴阳属性。

### 2.5 宫位吉凶评估

评分公式：基础分60 + 星曜加减 + 星组生克 + 宫星生克

| 评分区间 | 等级 |
|----------|------|
| ≥ 80 | 大吉 |
| 65-79 | 吉 |
| 50-64 | 中平 |
| 35-49 | 凶 |
| < 35 | 大凶 |

特殊吉凶组合：
- 五黄(5)临宫：-15~-20分
- 二黑(2)临宫：-8~-10分
- 八白(8)临宫：+10~12分
- 九紫(9)临宫：+8~10分
- 山向合十（山星+向星=10）：+10分
- 运星生宫：+5分
- 运星克宫：-5分

### 2.6 年星计算

```
中心星 = (1 - (年份 - 1900)) mod 9
若中心星 ≤ 0 → 中心星 += 9
```

## 三、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `divine(params)` | `{ sitting, facing, buildYear, currentYear }` | 风水排盘结果 | 主入口 |
| `getPeriod(year)` | 年份 | 元运数字 | 获取年份对应的元运 |
| `getPeriodChart(periodNum)` | 元运数字 | 运盘数组 | 获取运盘 |
| `getAnnualStars(year)` | 年份 | 年星数组 | 获取年星飞泊 |
| `fullAnalysis(sitting, facing, buildYear, currentYear)` | 坐向+年份 | 完整分析结果 | 综合风水分析 |
| `MOUNTAINS_24` | - | 二十四山数组 | 二十四山列表 |
| `STARS` | - | 九星属性对象 | 九星详细信息 |

### 返回结构

```javascript
{
  sitting: string,         // 坐山
  facing: string,          // 朝向
  buildYear: number,       // 建房年份
  currentYear: number,     // 当前年份
  periodNum: number,       // 元运数字
  overallScore: number,    // 综合评分 (0-100)
  overallLevel: string,    // 综合等级 ('上吉'|'中吉'|'中平'|'凶'|'大凶')
  palaces: Array<{
    idx: number,           // 宫位索引
    name: string,          // 宫名
    gua: string,           // 八卦
    wuxing: string,        // 五行
    periodStar: number,    // 运星
    mountainStar: number,  // 山星
    facingStar: number,    // 向星
    annualStar: number,    // 年星
    score: number,         // 评分
    level: string,         // 等级
    notes: string[],       // 吉评
    warnings: string[]     // 凶评
  }>,
  bestPalace: object,      // 最佳宫位
  worstPalace: object,     // 最差宫位
  periodChart: number[],   // 运盘
  annualStars: number[],   // 年星盘
  mountainStars: number[], // 山星盘
  facingStars: number[]    // 向星盘
}
```

## 四、拼户型建造器（UI组件）

详见 `static/js/components/fengshui.js`：
- 9种房间类型：客厅、主卧、次卧、厨房、餐厅、卫生间、书房、阳台、玄关
- 多网格尺寸：3×3、4×3、4×4、5×4、5×5
- 拖拽放置房间，动态映射到九宫格
- 罗盘旋转调整坐向（鼠标拖拽+触摸）
- 户型图上传（拖拽调整位置、滚轮缩放、透明度控制）
