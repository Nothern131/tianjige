# 天机阁 · 风水引擎 - 玄空飞星算法说明

**文件**：`static/js/fengshui-engine.js`

## 概述
玄空飞星风水算法核心，基于三元九运理论，实现纯前端算法排盘。支持二十四山坐向、三元九运、九宫飞泊、年星飞布，输出九宫吉凶评估和风水建议。

## 核心算法

### 1. 三元九运

| 元运 | 时间范围 | 对应星数 |
|------|----------|----------|
| 上元一运 | 1864-1883 | 一白（水） |
| 上元二运 | 1884-1903 | 二黑（土） |
| 上元三运 | 1904-1923 | 三碧（木） |
| 中元四运 | 1924-1943 | 四绿（木） |
| 中元五运 | 1944-1963 | 五黄（土） |
| 中元六运 | 1964-1983 | 六白（金） |
| 下元七运 | 1984-2003 | 七赤（金） |
| 下元八运 | 2004-2023 | 八白（土） |
| 下元九运 | 2024-2043 | 九紫（火） |

- 每运20年，共180年为一周期
- 当前为**九运**（2024-2043），中宫为9紫

### 2. 二十四山

**方位分布**（顺时针）：
```
壬 子 癸 | 丑 艮 寅 | 甲 卯 乙 | 辰 巽 巳 | 丙 午 丁 | 未 坤 申 | 庚 酉 辛 | 戌 乾 亥
```

- 每山15度，24山共360度
- **八卦归属**：
  - 坎卦：壬(330°)、子(0°)、癸(30°)
  - 艮卦：丑(30°)、艮(45°)、寅(60°)
  - 震卦：甲(60°)、卯(90°)、乙(120°)
  - 巽卦：辰(120°)、巽(135°)、巳(150°)
  - 离卦：丙(150°)、午(180°)、丁(210°)
  - 坤卦：未(210°)、坤(225°)、申(240°)
  - 兑卦：庚(240°)、酉(270°)、辛(300°)
  - 乾卦：戌(300°)、乾(315°)、亥(330°)

### 3. 九宫飞泊

**洛书飞布轨迹**（中五 → 乾六 → 兑七 → 艮八 → 离九 → 坎一 → 坤二 → 震三 → 巽四）

```
      乾六(西北)
      /   \
  兑七(西)  艮八(东北)
      |      |
  坎一(北)  中五(中)  离九(南)
      |      |
  震三(东)  坤二(西南)
      \   /
      巽四(东南)
```

**飞星排盘逻辑**：
1. **运星**：当前元运的飞星分布（中宫起运数，按洛书轨迹飞布）
2. **山星**：以坐山所在宫位的运星为中宫，按顺飞或逆飞布星
3. **向星**：以朝向所在宫位的运星为中宫，按顺飞或逆飞布星

### 4. 年星飞布

- **基准**：1900年中宫为1白
- **算法**：逐年递减1，超过9则归1
- 例：2024年 = 2024 - 1900 + 1 = 125 → 125 % 9 = 8 → 中宫为8白

### 5. 宫位评估算法

每个宫位综合评估四项飞星：

| 飞星 | 含义 |
|------|------|
| 运星 | 当前元运的飞星分布 |
| 山星 | 坐山决定的飞星（主人丁） |
| 向星 | 朝向决定的飞星（主财运） |
| 年星 | 当年流年飞星（主当年吉凶） |

**评分规则**：
- 基础分：60分
- 五黄临宫：-15～-20分（大凶）
- 二黑病符：-8～-10分（凶）
- 八白旺财：+10～+12分（吉）
- 九紫喜庆：+8～+10分（吉）
- 一白文昌：+6～+8分（吉）
- 六白权贵：+6～+8分（吉）
- 山向合十：+10分（大吉）
- 五行生克：±5分

**等级划分**：
- ≥80：大吉
- 65-79：吉
- 50-64：中平
- 35-49：凶
- <35：大凶

**总体评估**：九宫评分取平均值
- ≥75：上吉
- ≥60：中吉
- ≥45：中平
- ≥30：凶
- <30：大凶

## 技术实现

- **纯前端算法**：所有计算在浏览器JavaScript中执行，零API调用
- **无外部依赖**：纯JS实现，不依赖任何第三方库
- **响应式设计**：支持桌面端和移动端
