# 风水引擎 · 体验页 v3.0（拼户型建造器）

**文件**：`ep1-fengshui.html`（2026-07-29 更新）

## 概述
v3.0 在 v2.0 玄空飞星排盘基础上，新增**拼户型建造器**功能，支持多网格尺寸户型拼建、房间放置、实时风水排盘联动。

## 新增功能

### 1. 多网格尺寸支持（核心新增）

**支持的5种网格尺寸**：
- 3×3（默认）
- 4×3
- 4×4
- 5×4
- 5×5

**技术实现**：
- **CSS变量驱动**：通过 `--grid-cols` 和 `--grid-rows` 两个CSS变量控制网格行列数
  ```css
  .builder-grid {
    display: grid;
    grid-template-columns: repeat(var(--grid-cols, 3), 1fr);
    grid-template-rows: repeat(var(--grid-rows, 3), 1fr);
    gap: 3px;
  }
  ```
- **JavaScript动态生成**：`regenerateGrid(cols, rows)` 函数根据选择的行列数重建所有网格单元格
- **宫殿映射算法**：不同尺寸网格下，每个网格单元格通过 `(col*3/cols, row*3/rows)` 映射到3×3九宫格宫殿索引，确保宫殿分布逻辑一致

### 2. 房间放置系统

**9种房间类型**（左侧面板）：
1. 客厅 🛋️
2. 主卧 🛏️
3. 次卧 🛏️
4. 厨房 🍳
5. 餐厅 🍽️
6. 卫生间 🚽
7. 书房 📚
8. 阳台 🌿
9. 玄关 🚪

**交互功能**：
- **点击放置**：点击网格单元格放置当前选中的房间
- **橡皮擦按钮**：清除单个格子中的房间
- **随机布局**：自动随机分配所有房间到网格单元格
- **清空所有**：一键清除所有房间

### 3. 网格大小选择器

**HTML结构**：

- `.grid-size-label` 显示"网格："提示文字

### 4. 罗盘交互重构（核心修复）

**问题背景**：原实现中罗盘Canvas的 `pointer-events:auto` 属性导致罗盘拦截了网格单元格的点击事件，用户无法点击放置房间。

**解决方案**：
1. **视觉分离**：罗盘Canvas移除 `interactive` 类，设置 `pointer-events:none`，仅作为装饰性视觉元素，不响应任何鼠标事件
2. **事件迁移**：旋转拖拽逻辑从 `compassCanvas` 迁移到 `gridWrapper`（包含Canvas和网格的父容器）
3. **区域判断**：通过点击位置距中心的距离判断触发区域：
   - **网格区域**（0~38%半径）：允许网格点击放置房间
   - **外环区域**（42%~51%半径）：触发罗盘旋转，显示 `grab` 光标
   - **中间空白区域**（38%~42%半径）：无操作
4. **滚动条支持**：移除 `overflow: hidden`，添加 `overflow-y: auto` 解决内容过长时无法滚动的问题

**JavaScript关键逻辑**：
```javascript
gridWrapper.addEventListener('mousedown', function(e) {
  var rect = gridWrapper.getBoundingClientRect();
  var mx = e.clientX - rect.left;
  var my = e.clientY - rect.top;
  var cx = rect.width / 2, cy = rect.height / 2;
  var dist = Math.sqrt((mx - cx) * (mx - cx) + (my - cy) * (my - cy));
  var wrapperSize = Math.min(rect.width, rect.height);
  
  // 外环区域判断：42% ~ 51% 半径
  var rInner = wrapperSize * 0.42;
  var rOuter = wrapperSize * 0.51;
  if (dist >= rInner && dist <= rOuter) {
    isDragging = true;
    dragStartAngle = Math.atan2(my - cy, mx - cx);
    dragStartCompassAngle = compassAngle;
    gridWrapper.style.cursor = 'grabbing';
    e.preventDefault();
  }
});
```

### 5. 布局优化

- `.grid-container` 由 `flex-direction: row` 改为 `flex-direction: column`，纵向排列
- 网格选择器 `justify-content: center` 居中显示，`margin-bottom: 10px` 与Canvas分隔
- Canvas与网格区域通过 `pointer-events: none` 实现视觉重叠但事件分离

## 技术细节

### 网格生成函数 `regenerateGrid(cols, rows)`

```javascript
function regenerateGrid(cols, rows) {
  builderGrid.style.setProperty('--grid-cols', cols);
  builderGrid.style.setProperty('--grid-rows', rows);
  builderGrid.innerHTML = '';
  
  var totalCells = cols * rows;
  gridRooms = new Array(totalCells).fill(null);
  
  for (var i = 0; i < totalCells; i++) {
    var cell = document.createElement('div');
    cell.className = 'grid-cell';
    cell.dataset.gridIdx = i;
    
    // 网格位置 → 九宫格宫殿索引映射
    var col = i % cols;
    var row = Math.floor(i / cols);
    var palaceCol = Math.floor(col * 3 / cols);
    var palaceRow = Math.floor(row * 3 / rows);
    var palaceIdx3x3 = Math.min(palaceRow * 3 + palaceCol, 8);
    var pi = GRID_DISPLAY[palaceIdx3x3];  // 获取宫殿名称如"乾宫"
    
    cell.dataset.palaceIdx = pi;
    cell.innerHTML = '<span class="cell-placeholder">+</span>';
    
    cell.addEventListener('click', function() {
      // 房间放置逻辑
      var roomId = currentRoomType;
      if (roomId) {
        gridRooms[this.dataset.gridIdx] = roomId;
        this.innerHTML = '<span class="cell-room">' + getRoomIcon(roomId) + '</span>';
        updateCompassAndFengShui();  // 实时联动排盘
      }
    });
    
    builderGrid.appendChild(cell);
  }
}
```

### 随机布局函数 `randomizeGrid()`

根据当前网格大小随机分配房间类型到各单元格，使用 Fisher-Yates 洗牌算法确保均匀分布。

### 清空功能 `clearAllRooms()`

遍历所有网格单元格，恢复为空，并重置 `gridRooms` 数组，同时触发 `updateCompassAndFengShui()` 重置风水排盘。
