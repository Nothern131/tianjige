# 周公解梦引擎 · 技术文档

> 版本：v1 | 文件：`static/js/zhougong-engine.js` | 类别：文本类
> 体系参考：周公解梦经典文库 · 200+条梦境

## 一、概述

周公解梦引擎基于经典解梦文库，支持200+条梦境条目的关键词匹配和解读。新增问事领域体系，可将梦境元素映射到9个具体事域（事业/感情/财运/健康/学业/家庭/人际/出行/综合），给出针对性交叉分析。

## 二、核心算法

### 2.1 梦境分类（16类）

天象、地理、人物、身体、动物、植物、建筑、器物、衣饰、饮食、文书、交通、水火、佛道、丧葬、其他

### 2.2 关键词匹配

```
精确匹配：输入文本包含梦境关键词 → 返回匹配条目
模糊匹配：精确匹配无结果 → 反向匹配（关键词中任意字符在输入中出现）
```

### 2.3 五行归属

| 五行 | 关键词 |
|------|--------|
| 金 | 刀、剑、金、银、铁、铜、钟、戒指、金属、钥匙 |
| 木 | 树、花、草、竹、木、植物、森林、梅花、荷花 |
| 水 | 水、海、河、雨、雪、冰、泉、鱼、船、游泳 |
| 火 | 火、灯、光、太阳、炉、烛、红、赤、亮 |
| 土 | 山、地、土、石、墙、屋、房、墓、坟、塔 |

### 2.4 吉凶综合判断

```
吉数 ≥ 2 且 吉数 > 凶数 → 吉
凶数 ≥ 2 且 凶数 > 吉数 → 凶
其他 → 中
```

### 2.5 问事领域检测（9域）

对用户所问之事进行关键词匹配，检测属于哪个领域：

| 领域 | 关键词示例 |
|------|------------|
| 事业 | 事业、工作、职场、升职、跳槽、创业 |
| 感情 | 感情、爱情、婚姻、恋爱、分手、相亲 |
| 财运 | 财运、钱、财富、投资、理财、股票 |
| 健康 | 健康、身体、疾病、生病、康复、手术 |
| 学业 | 学业、考试、学习、成绩、高考、考研 |
| 家庭 | 家庭、父母、子女、孩子、亲情、婆媳 |
| 人际 | 朋友、社交、人际、合伙、小人、贵人 |
| 出行 | 出行、旅游、出国、移民、远行、搬家 |
| 综合 | 运势、命运、运气、整体、综合 |

### 2.6 梦境→事域映射

每个梦境关键词在不同事域下有专门的解读映射表（`mapDreamToDomain`），约100+条映射规则。例如：
- 梦见龙→事业：贵人提携，重大项目可推进
- 梦见龙→感情：长辈牵线，良缘将至
- 梦见鱼→财运：大鱼跃水主横财

## 三、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `divine(text, question)` | 梦境描述文本，所问之事（可选） | 解梦结果对象 | 主入口，解梦+问事分析 |
| `getCategories()` | 无 | 分类数组 | 获取所有梦境分类 |
| `getAllDreams()` | 无 | 梦境条目数组 | 获取全部200+条梦境 |
| `searchByCategory(cat)` | 分类ID | 该分类下的梦境条目 | 按分类搜索 |

### 返回结构

```javascript
{
  input: string,           // 原始输入
  question: string,        // 所问之事
  results: Array,          // 匹配的梦境条目
  interpretation: string,  // 完整解读文本
  questionAnalysis: string,// 问事交叉分析（如有）
  domain: {                // 检测到的领域（如有）
    key: string,
    name: string,
    icon: string
  },
  ji: string,              // 总体吉凶 ('吉'|'中'|'凶')
  categories: string[],    // 涉及的分类
  count: number            // 匹配条目数
}
```

### 梦境条目结构

```javascript
{
  keyword: string,         // 关键词
  cat: string,             // 分类ID
  ji: string,              // 吉凶 ('吉'|'中'|'凶')
  interpretation: string   // 解读文本
}
```
