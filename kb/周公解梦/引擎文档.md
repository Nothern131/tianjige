# 周公解梦引擎 · 技术文档

> 版本：v2 | 文件：`static/js/zhougong-engine.js` | 类别：文本类
> 体系参考：周公解梦经典文库 130 条 + 现代民俗补编 30 条，共 160 条

## 一、概述

周公解梦引擎基于 160 条梦境条目（含 30 条现代补编）的关键词匹配和解读。新增问事领域体系，可将梦境元素映射到 9 个具体事域（事业/感情/财运/健康/学业/家庭/人际/出行/综合），给出针对性交叉分析。

## 二、核心算法

### 2.1 梦境分类（16类）

天象、地理、人物、身体、动物、植物、建筑、器物、衣饰、饮食、文书、交通、水火、佛道、丧葬、其他

### 2.2 关键词匹配

```
1. 同义词映射：如「掉牙」→「牙齿」、「打雷」→「雷电」、「妈妈」→「母亲」
2. 精确匹配：输入文本包含梦境关键词 → 返回匹配条目
3. 长词优先：单字关键词若只作为更长关键词的一部分出现，则剔除
   （如「手机」不再额外命中「手」，「公交车」不再额外命中「车」）
4. 无匹配时返回空结果并提示未收录，不再用单字模糊回退制造误判
```

### 2.2.1 现代补编

在保留 130 条经典文库的基础上，新增 30 条现代民俗梦象，覆盖四类此前缺失的场景：

- 亲属：父母、母亲、父亲、祖辈、配偶、恋人、兄弟姐妹、朋友、亲戚
- 职场：老板、同事、上班、公司、升职、加薪、辞职、面试
- 现代器物：电脑、网络、电梯、地铁、公交车
- 生活事件：搬家、买房、中奖、破产、离婚、分手、迟到、摔倒

亲属条目的意象参考《断梦秘书》《敦煌本梦书》等传统梦书的常见主题；职场、现代器物、生活事件为项目组按通行民俗意象整理的现代释义，非古籍原文，条目内以 `source` 字段标注。

### 2.4 吉凶综合判断

```
吉数 ≥ 2 且 吉数 > 凶数 → 吉
凶数 ≥ 2 且 凶数 > 吉数 → 凶
其他 → 中
```

### 2.5 问事领域检测（9域）

对用户所问之事进行关键词匹配，检测属于哪个领域：

| 领域 | 关键词示例 |
|------|------------|
| 事业 | 事业、工作、职场、升职、跳槽、创业 |
| 感情 | 感情、爱情、婚姻、恋爱、分手、相亲 |
| 财运 | 财运、钱、财富、投资、理财、股票 |
| 健康 | 健康、身体、疾病、生病、康复、手术 |
| 学业 | 学业、考试、学习、成绩、高考、考研 |
| 家庭 | 家庭、父母、子女、孩子、亲情、婆媳 |
| 人际 | 朋友、社交、人际、合伙、小人、贵人 |
| 出行 | 出行、旅游、出国、移民、远行、搬家 |
| 综合 | 运势、命运、运气、整体、综合 |

### 2.6 梦境→事域映射

每个梦境关键词在不同事域下有专门的解读映射表（`mapDreamToDomain`），约100+条映射规则。例如：
- 梦见龙→事业：贵人提携，重大项目可推进
- 梦见龙→感情：长辈牵线，良缘将至
- 梦见鱼→财运：大鱼跃水主横财

## 三、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `divine(text, question)` | 梦境描述文本，所问之事（可选） | 解梦结果对象 | 主入口，解梦+问事分析 |
| `getCategories()` | 无 | 分类数组 | 获取所有梦境分类 |
| `getAllDreams()` | 无 | 梦境条目数组 | 获取全部160条梦境 |
| `searchByCategory(cat)` | 分类ID | 该分类下的梦境条目 | 按分类搜索 |

### 返回结构

```javascript
{
  input: string,           // 原始输入
  question: string,        // 所问之事
  results: Array,          // 匹配的梦境条目
  interpretation: string,  // 完整解读文本
  questionAnalysis: string,// 问事交叉分析（如有）
  domain: {                // 检测到的领域（如有）
    key: string,
    name: string,
    icon: string
  },
  ji: string,              // 总体吉凶 ('吉'|'中'|'凶')
  categories: string[],    // 涉及的分类
  count: number            // 匹配条目数
}
```

### 梦境条目结构

```javascript
{
  keyword: string,         // 关键词
  cat: string,             // 分类ID
  ji: string,              // 吉凶 ('吉'|'中'|'凶')
  interpretation: string   // 解读文本
}
```
