# 奇门遁甲引擎 v1 · 引擎文档

> 文件：`static/js/qimen-engine.js` | 流派：时家奇门 | 全局：`QimenEngine`

## 一、概述

奇门遁甲引擎，基于**时家奇门**体系。纯前端算法，零 API 调用。根据日期和时辰，自动确定节气→阴阳遁→局数，排地盘、天盘、八门、九星、八神，生成完整奇门盘和解读。

## 二、核心算法

### 2.1 节气与局数

- **24节气近似日期表**：冬至12月22日 ~ 大雪12月7日
- **阳遁**：冬至→芒种，共12节气，局数1-9（冬至起1局）
- **阴遁**：夏至→大雪，共12节气，局数9-1（夏至起9局）

### 2.2 排盘流程

```
日期 → 节气 → 阴阳遁+局数
日期 → 日干支 → 时干支
局数 → 排地盘（戊己庚辛壬癸丁丙乙顺/逆排九宫）
时干支 → 排天盘+星盘（值符星随天盘转动）
时干支 → 排八门（值使门随值符转动）
值符宫 → 排八神（阳遁顺排/阴遁逆排）
```

### 2.3 地盘

- **阳遁**：戊在ju宫，己庚辛壬癸丁丙乙依次顺行（1→2→3→...→9）
- **阴遁**：戊在ju宫，己庚辛壬癸丁丙乙依次逆行（1→9→8→...→2）

### 2.4 天盘与星盘

- 值符星 = 时辰干所在宫位的原始星
- 天盘干 = 地盘干随值符星旋转
- 九星：天蓬/天芮/天冲/天辅/天禽/天心/天柱/天任/天英

### 2.5 八门

- 八门：休/生/伤/杜/景/死/惊/开
- 原始宫位：休1/生8/伤3/杜4/景9/死2/惊7/开6
- 值使门 = 时辰地支对应的原始门，随值符旋转

### 2.6 八神

- 阳遁顺排：值符→螣蛇→太阴→六合→白虎→玄武→九地→九天
- 阴遁逆排：值符→螣蛇→太阴→六合→白虎→玄武→九地→九天（逆序）

## 三、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `divine(dateStr, shichen, juStr)` | 日期/时辰/局数 | 完整奇门盘 | 起局 |
| `SOLAR_TERMS` | 无 | 24节气表 | 静态属性 |
| `YANG_DUN_JU` | 无 | 阳遁局数表 | 静态属性 |
| `YIN_DUN_JU` | 无 | 阴遁局数表 | 静态属性 |

## 四、解读体系

1. **局象概述**：阴阳遁+局数
2. **旬首分析**：六甲旬首遁藏
3. **宫位分析**：9宫星门神干逐一解读
4. **吉凶判断**：吉门（休生开）+ 吉星（天心天任天辅天禽）+ 吉神（值符太阴六合九天九地）
5. **出行建议**：推荐吉方出行
