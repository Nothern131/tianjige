# 太乙神数引擎 · 技术文档

> 版本：v1 | 文件：`static/js/taiyi-engine.js` | 类别：时空类
> 体系参考：太乙积年 · 十六神 · 九宫 · 五福三基 · 四神

## 一、概述

太乙神数是古代三式（太乙、奇门、六壬）之一，主推算国运天时。本引擎实现核心算法：太乙积年计算、十六神排布、九宫定位、五福三基四神推算，输出完整的太乙解读文本。

## 二、核心算法

### 2.1 太乙积年

```
积年 = 上古甲子年(10153917) + 目标年份
局数 = 积年 mod 24
```

### 2.2 太乙行宫

太乙每24年巡行一周九宫。阳局顺行，阴局逆行。18局一个完整循环：
- 局数0-8：顺行乾→离→艮→震→中→兑→坤→坎→巽
- 局数9-17：逆行

### 2.4 五福

```
五福 = floor(积年 mod 225 / 45)
五福入宫 = 九宫[五福 mod 9]
```

### 2.5 三基（君基、臣基、民基）

```
君基 = floor(积年 mod 360 / 30) mod 9
臣基 = floor((积年 + 120) mod 360 / 30) mod 9
民基 = floor((积年 + 240) mod 360 / 30) mod 9
```

### 2.6 四神（天乙、地乙、直符、四神）

```
天乙 = floor(积年 mod 360 / 36) mod 9
地乙 = floor((积年 + 180) mod 360 / 36) mod 9
直符 = floor((积年 + 90) mod 360 / 36) mod 9
四神 = floor((积年 + 270) mod 360 / 36) mod 9
```

## 三、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `divine(date, time)` | 日期字符串 `YYYY-MM-DD`，时辰名称（如 `'子时'`） | 太乙盘结果对象 | 主入口，执行完整太乙推算 |

### 返回结构

```javascript
{
  epoch: string,           // 纪元名称（如 '上元·第N纪'）
  ji_nian: number,         // 太乙积年数
  gods: Array<{name, position, auspicious, wuxing}>,  // 十六神排布
  wufu: string,            // 五福解读
  sanji: string,           // 三基解读
  taiyi_position: string,  // 太乙落宫（如 '乾宫（西北）'）
  interpretation: string   // 完整解读文本
}
```
