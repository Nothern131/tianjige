# 六爻引擎 v1 · 引擎文档

> 文件：`static/js/liuyao-engine.js` | 流派：鬼谷子·京房纳甲 | 全局：`LiuyaoEngine`

## 一、概述

六爻占卜引擎，基于**鬼谷子·京房纳甲**体系。纯前端算法，零 API 调用。支持六爻起卦、64卦识别、纳甲排盘、六亲六兽、世应分析、变卦推演。

## 二、核心算法

### 2.1 64卦体系

- **八宫卦序**：乾/坎/艮/震/巽/离/坤/兑，每宫8卦（八纯→一世→二世→三世→四世→五世→游魂→归魂）
- **六爻 → 卦名**：通过 `YAO_TO_GUA` 映射表快速查找
- **世爻定位**：每卦内置世爻位置（1-6）

### 2.2 京房纳甲

八宫卦各有固定的纳甲配置，从初爻到上爻每爻配天干+地支：

| 宫 | 初爻 | 二爻 | 三爻 | 四爻 | 五爻 | 上爻 |
|----|------|------|------|------|------|------|
| 乾 | 甲子 | 甲寅 | 甲辰 | 壬午 | 壬申 | 壬戌 |
| 坎 | 戊寅 | 戊辰 | 戊午 | 戊申 | 戊戌 | 戊子 |
| 艮 | 丙辰 | 丙午 | 丙申 | 丙戌 | 丙子 | 丙寅 |
| 震 | 庚子 | 庚寅 | 庚辰 | 庚午 | 庚申 | 庚戌 |
| 巽 | 辛丑 | 辛亥 | 辛酉 | 辛未 | 辛巳 | 辛卯 |
| 离 | 己卯 | 己丑 | 辛亥 | 己酉 | 己未 | 己巳 |
| 坤 | 乙未 | 乙巳 | 乙卯 | 癸丑 | 癸亥 | 癸酉 |
| 兑 | 丁巳 | 丁卯 | 丁丑 | 丁亥 | 丁酉 | 丁未 |

### 2.3 六亲规则

以**卦宫五行**为"我"，每一爻纳甲地支的五行与"我"的关系：
- 同我 → 兄弟
- 生我 → 父母
- 我生 → 子孙
- 克我 → 官鬼
- 我克 → 妻财

### 2.4 六兽规则

根据日干确定起始兽，依次排列：青龙→朱雀→勾陈→螣蛇→白虎→玄武

### 2.5 变卦

动爻处阴阳互变，生成变卦，通过 `YAO_TO_GUA` 快速查找变卦名称。

## 三、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `divine(lines)` | 6个爻对象数组 `[{type, changing}]` | 完整卦象结果 | 六爻起卦 |
| `listAllGuas()` | 无 | 64卦列表 | 列出所有卦 |
| `findGua(name)` | 卦名 | 卦对象 | 按名称查找 |

## 四、解读体系

解读分为6个部分：
1. **卦象总览**：本卦名称、宫位、上下卦象意
2. **世应分析**：世爻（占者）与应爻（所占之事）的关系
3. **动爻分析**：每爻的六亲+六兽解读
4. **六亲布局**：六亲分布统计
5. **六兽提示**：世爻临兽解读
6. **综合断语**：结合世爻六亲、动爻数量、变卦的综合判断
