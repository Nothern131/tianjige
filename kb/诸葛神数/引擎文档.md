# 诸葛神数引擎 · 技术文档

> 版本：v1 | 文件：`static/js/zhuge-engine.js` | 类别：即时类
> 体系参考：诸葛亮 · 384签

## 一、概述

诸葛神数源于诸葛亮行军占卜之法，共384签。本引擎支持三种起卦方式：报字法（输入汉字计算笔画）、报数法（直接输入三个数字）、随机法（随机生成签号），输出签号、诗签、解读和判断。

## 二、核心算法

### 2.1 报字法（wordMethod）

对用户输入的汉字逐字计算笔画数，取前三个字：
```
字1笔画 → 除8取余（若不超过8则直接使用）
字2笔画 → 除8取余
字3笔画 → 除6取余
签号 = 字1笔画 × 字2笔画 × 字3笔画（取模384）
```

内置常用汉字笔画查找表（STROKE_MAP），覆盖约2000+常用字。

### 2.2 报数法（numberMethod）

用户直接输入三个数字：
```
签号 = (n1 * n2 * n3) % 384
若签号为0 → 签号 = 384
```

### 2.3 随机法（randomMethod）

随机生成1-384之间的签号。

### 2.4 签文查找

384签分为上上、中上、中下、下下四等：
- 上上签：签号范围 1-96
- 中上签：签号范围 97-192
- 中下签：签号范围 193-288
- 下下签：签号范围 289-384

每签包含：签号、等级、签诗、解读、判断。

## 三、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `divine(params)` | `{ method: 'word'|'number'|'random', words: string, numbers: [n1,n2,n3] }` | 签文对象 | 主入口，起卦并返回签文 |
| `getStrokeCount(char)` | 单个汉字 | 笔画数 | 查询汉字笔画数 |
| `getQianLibrary()` | 无 | 384签数组 | 获取完整签文库（只读） |
| `getTotalCount()` | 无 | 384 | 获取签文总数 |

### 返回结构

```javascript
{
  number: number,        // 签号 (1-384)
  level: string,         // 签等 ('上上'|'中上'|'中下'|'下下')
  poem: string,          // 签诗
  interpretation: string, // 详细解读
  verdict: string        // 判断结论
}
```

## 四、数据结构

### 签文等级

| 等级 | 签号范围 | 含义 |
|------|----------|------|
| 上上 | 1-96 | 大吉，万事亨通 |
| 中上 | 97-192 | 中吉，顺遂有助 |
| 中下 | 193-288 | 中平，有阻有助 |
| 下下 | 289-384 | 大凶，宜守不宜攻 |

### 起卦方式

| 方式 | 方法参数 | 输入 | 适用场景 |
|------|----------|------|----------|
| 报字法 | `word` | 汉字字符串 | 有具体问题想用文字表达 |
| 报数法 | `number` | 三个数字 [n1,n2,n3] | 有特定数字（如日期、随机数） |
| 随机法 | `random` | 无 | 快速占卜，无特定输入 |
