# 大六壬引擎 · 技术文档

> 版本：v1 | 文件：`static/js/daliuren-engine.js` | 类别：时空类
> 体系参考：邵彦和《六壬断案》· 陈公献《大六壬指南》· 郭御青《六壬大全》

## 一、概述

大六壬是古代三式之一，以天地盘为框架，通过四课三传推演人事吉凶。本引擎实现完整的六壬排盘链：月将加时→天盘→四课→九宗门法→三传→十二天将→六亲→课体判断→解读。

## 二、核心算法

### 2.1 排盘流水线

```
公历日期 → 日干支
时辰 → 占时
月将 = 根据公历月日确定（中气前后切换）
天盘 = 月将加占时，顺行十二辰
四课 = 日干寄宫→天盘→上神（四课连乘）
三传 = 九宗门法确定（初传→中传→末传）
十二天将 = 贵人诀 + 昼夜顺逆
六亲 = 日干五行 vs 三传地支五行
课体判断 → 解读
```

### 2.4 十二天将（贵人诀）

```
贵人诀：甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢马虎，此是贵人方
```

昼夜判断：卯时(3)到申时(8)为昼，酉时到寅时为夜。
顺逆规则：贵人在巳(5)到戌(10)之间逆行，其他顺行。

十二天将顺逆排布：贵人→螣蛇→朱雀→六合→勾陈→青龙→天空→白虎→太常→玄武→太阴→天后

### 2.5 六亲关系

| 关系 | 条件 | 说明 |
|------|------|------|
| 父母 | 地支五行生天干五行 | 生我者 |
| 子孙 | 天干五行生地支五行 | 我生者 |
| 官鬼 | 地支五行克天干五行 | 克我者 |
| 妻财 | 天干五行克地支五行 | 我克者 |
| 兄弟 | 五行相同 | 同我者 |

## 三、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `divine(dateStr, hourNum)` | 日期 `YYYY-MM-DD`，时辰编号 0-11（子时=0） | 六壬排盘结果 | 主入口 |
| `getYueJiang(month, day)` | 公历月、日 | 月将地支 | 获取月将 |
| `JIANG_NAMES` | - | - | 月将名称对照表 |
| `ZHI` | - | - | 地支数组 |
| `GAN` | - | - | 天干数组 |

### 返回结构

```javascript
{
  date: string,            // 占卜日期
  zhan_shi: string,        // 占时地支
  yue_jiang: string,       // 月将地支
  yue_jiang_name: string,  // 月将名称
  ri_gan: string,          // 日干
  ri_zhi: string,          // 日支
  tian_pan: object,        // 天盘 {地盘地支: 天将地支}
  si_ke: object,           // 四课 {ke1, ke2, ke3, ke4, ganJi}
  san_chuan: object,       // 三传 {chu, zhong, mo, type, keInfo}
  tian_jiang: object,      // 十二天将 {地支: 天将名}
  ke_name: string,         // 课体名称
  chuan: string,           // 三传字符串 '初→中→末'
  interpretation: string,  // 完整解读
  level: string            // 吉凶等级 ('吉'|'中平'|'偏凶')
}
```
