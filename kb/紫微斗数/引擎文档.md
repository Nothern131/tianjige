# 紫微斗数引擎 · 技术文档

> 版本：v1 | 文件：`static/js/ziwei-engine.js` | 类别：命盘类
> 体系参考：陈希夷《紫微斗数全书》· 中州派 · 天纪紫微

## 一、概述

紫微斗数是命盘推演术数，以星曜为纲、宫位为目。本引擎实现完整的紫微斗数排盘链：农历转换→安命宫/身宫→定十二宫天干→定五行局→安紫微星→安十四主星→安辅星→四化→十二宫构建→解读。

## 二、核心算法

### 2.1 排盘流水线

```
公历日期 → 农历转换（简化版）
生年干支 → 寅首天干 → 十二宫天干
农历月 + 时辰 → 安命宫（寅起正月顺数至生月，逆数至生时）
农历月 + 时辰 → 安身宫（寅起正月顺数至生月，顺数至生时）
命宫干支 → 纳音五行 → 五行局
五行局数 + 农历日 → 安紫微星
紫微星位置 → 安十四主星（紫微系+天府系）
年支 + 月 + 时 + 年干 → 安辅星（左辅、右弼、文昌、文曲、天魁、天钺、禄存、擎羊、陀罗、火星、铃星、地空、地劫）
年干 → 四化（化禄、化权、化科、化忌）
命宫地支 → 十二宫构建（命宫→兄弟→夫妻→...→父母）
合并星曜 → 解读
```

### 2.2 安命宫/身宫

```
命宫：寅宫起正月，顺数至生月 → 起子时，逆数至生时
身宫：寅宫起正月，顺数至生月 → 起子时，顺数至生时
```

### 2.3 定五行局（纳音）

| 金 | 金四局 |
| 木 | 木三局 |

| 火 | 火六局 |
| 土 | 土五局 |

### 2.4 十四主星排布

**紫微系**（逆时针隔一安一星）：
紫微→天机→(空)→太阳→武曲→天同→(空)→廉贞

**天府系**（顺时针隔一安一星）：
天府→太阴→贪狼→巨门→天相→天梁→七杀→(空)→破军

紫微→天府位置映射：子→辰、丑→卯、寅→辰、卯→丑、辰→子、巳→亥、午→戌、未→酉、申→申、酉→未、戌→午、亥→巳

## 三、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `paipan(params)` | `{ year, month, day, hour, gender, isLunar }` | 紫微斗数排盘结果 | 主入口 |
| `GONG_NAMES` | - | 十二宫名称数组 | 宫名对照 |

### 返回结构

```javascript
{
  农历年: number,
  农历月: number,
  农历日: number,
  年干: string,           // 生年天干
  年支: string,           // 生年地支
  命宫: string,           // 命宫地支
  命宫主星: string,       // 命宫主星（如 '紫微、天府'）
  身宫: string,           // 身宫地支
  五行局: string,         // 如 '木三局'
  十二宫: Array<{
    name: string,          // 宫名
    zhi: string,           // 地支
    gan: string,           // 天干
    ganZhi: string,        // 干支
    stars: string[],       // 该宫星曜
    isMingGong: boolean,   // 是否为命宫
    isShenGong: boolean    // 是否为身宫
  }>,
  四化: { lu, quan, ke, ji },
  紫微星落: string,       // 紫微星落宫地支
  所有星曜: object,        // {地支: [星曜名称]}
  interpretation: string,  // 完整解读
  总体运势: string         // 总体判断
}
```
