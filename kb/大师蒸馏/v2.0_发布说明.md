# 大师蒸馏引擎 v2.0 发布说明（2026-07-29）

## 概述
v2.0 是一次重大重构，核心目标是解决分析内容过短的问题，增加详细推理、因果链和个性化分析。从简单的模板填充升级为完整的命理推演系统。

## 问题背景

| 问题 | 影响 |
|------|------|
| `generateSpecialtyParagraph` 仅生成2段通用分析 | 内容单薄，缺乏八字具体解读 |
| 缺少十神配置详解 | 无法体现四柱十神分布的深层含义 |
| 旺衰判断仅基于月令 | 未考虑四柱整体生扶和五行数量 |
| 没有格局分析 | 无法识别正官格、七杀格等重要格局 |
| 无用神喜忌推导 | 缺乏针对性的改运建议 |

## v2.0 新增功能

### 1. 十神计算系统
**文件**：`static/js/masters-engine.js`

```javascript
// SHISHEN_MAP - 五层映射结构
var SHISHEN_MAP = {
  木: { shengWo: { yin: '正印', yang: '偏印' }, ... },
  火: { shengWo: { yin: '偏印', yang: '正印' }, ... },
  // 土、金、水...
};

// SHISHEN_DESC - 十神详细解读
var SHISHEN_DESC = {
  '正印': '仁慈善良，聪慧好学，有贵人相助，主学识、名誉、母亲、长辈',
  '偏印': '领悟力强，独辟蹊径，有特殊才能，主偏门学问、继母、非正统',
  // 其他8种十神...
};

// SHISHEN_JIXIONG - 吉凶分类
var SHISHEN_JIXIONG = {
  '正印': '吉', '偏印': '平', '比肩': '平', '劫财': '平',
  '食神': '吉', '伤官': '平', '正财': '吉', '偏财': '吉',
  '正官': '吉', '七杀': '凶'
};
```

**使用方式**：在总论和专论中自动计算并显示四柱天干的十神名称，如"年干甲为正印，月干乙为食神"等。

### 2. 旺衰判断增强
**算法**：综合三个维度：
1. **月令本气**（权重最高）：月支对应的天干五行 vs 日主五行
2. **四柱生扶**：年/月/时柱天干地支对日主的生扶程度
3. **五行数量**：四柱中与日主同五行的个数

**输出**：旺 → 偏旺 → 中和 → 偏弱 → 弱（5个等级）

### 3. 格局分析系统
支持9种格局识别：
- 正官格、七杀格、正印格、偏印格
- 食神格、伤官格、正财格、偏财格
- 建禄格

每个格局包含**成格条件**和**败格条件**的判断逻辑。

### 4. 用神喜忌推导
基于旺衰和格局，自动推荐：
- **用神**：平衡日主旺衰、辅助格局的核心五行
- **喜神**：辅助用神的五行
- **忌神**：加重不利因素的五行

### 5. 六段式总论（`generateDetailedOverview`）
总论从2段扩展为6段结构化内容：

```
① 日主定位：日柱天干 + 五行 + 阴阳属性
② 旺衰格局：日主旺衰状态 + 格局名称
③ 十神配置：四柱十神分布详解（年/月/日/时干）
④ 用神喜忌：推荐用神、喜神，列出忌神
⑤ 大运趋势：当前大运和未来走势
⑥ 总体建议：综合性的命理指导
```

### 6. 详细专论（`generateDetailedSpecialty`）
专论从2段通用分析扩展为：每个段落包含十神配置 + 具体分析 + 建议。

支持4种分析类型：
| 类型 | 关键词 | 关注点 |
|------|--------|--------|
| wealth | 财富 | 财运、理财、富贵贫贱 |
| talent | 天赋 | 才艺、发展方向、潜能 |
| anti-internal-friction | 反内耗 | 压力来源、化解方法、心神安顿 |
| soulmate | 正缘 | 缘分特征、时间窗口、良缘佳期 |

## 函数变更概览

| 函数 | v1.0 | v2.0 |
|------|------|------|
| `analyze()` | 简单模板填充，返回 `{ opening, specialty, quote, closing }` | 六段式分析，返回 `{ opening, overview, specialty, quote, closing }` |
| `generateSpecialtyParagraph()` | 2段通用分析 | 多段详细分析（含十神+专项+建议） |
| - | - | 新增 `generateDetailedOverview()` 六段式总论 |
| - | - | 新增 `generateDetailedSpecialty()` 按类型展开的专论 |

## 测试验证

所有现有大师风格和模板均兼容新版本分析架构。各大师的 `openingTemplates`、`quoteTemplates`、`closingTemplates` 保持不变，仅分析中间的总论和专论部分填充更丰富。
