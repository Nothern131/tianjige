# 大师蒸馏引擎 · 技术文档

> 版本：v2.0 | 文件：`static/js/masters-engine.js` | 类别：输出层
> 体系参考：34位古今命理大师风格复刻

## 一、概述

大师蒸馏引擎是系统的输出层，将术数引擎的计算结果以34位古今命理大师的独特风格进行五段式呈现。v2.0大幅升级：新增十神计算系统、旺衰判断、格局分析、用神喜忌推导，从"模板填充"升级为"真分析"。

## 二、核心算法

### 2.1 十神计算系统

基于日主五行与各天干的关系，通过五层映射（生我/我生/克我/我克/同我 × 阴阳）确定十神：

| 十神 | 关系 | 吉凶 | 含义 |
|------|------|------|------|
| 正印 | 生我+异性 | 吉 | 仁慈善良，聪慧好学，贵人相助 |
| 偏印 | 生我+同性 | 平 | 领悟力强，独辟蹊径，特殊才能 |
| 比肩 | 同我+同性 | 平 | 独立自主，自尊心强，朋友多助 |
| 劫财 | 同我+异性 | 平 | 热情豪爽，社交能力强，易破财 |
| 食神 | 我生+同性 | 吉 | 温和宽厚，有口福，才艺出众 |
| 伤官 | 我生+异性 | 平 | 聪明机智，才华横溢，锋芒毕露 |
| 正财 | 我克+异性 | 吉 | 勤俭务实，财运稳定 |
| 偏财 | 我克+同性 | 吉 | 慷慨大方，财运起伏，意外之财 |
| 正官 | 克我+异性 | 吉 | 正直守法，有责任感 |
| 七杀 | 克我+同性 | 凶 | 果断刚毅，有魄力，压力大 |

### 2.2 旺衰判断

综合评分系统（满分125分）：
- 月令本气权重：40分（地支）
- 月干权重：25分
- 日支权重：20分
- 时干权重：15分
- 年干权重：10分
- 年支权重：8分
- 时支权重：7分
- 日主自身基础：15分

| 评分 | 旺衰 |
|------|------|
| ≥ 65 | 身旺 |
| 45-64 | 中和偏旺 |
| 30-44 | 中和偏弱 |
| < 30 | 身弱 |

### 2.3 格局分析（9种）

以月令取格，月令本气天干对应的十神即为格局：

| 格局 | 条件 | 成败要点 |
|------|------|----------|
| 正官格 | 月令正官 | 喜印化、食伤制，忌财生 |
| 七杀格 | 月令七杀 | 喜印化、食伤制，忌财生 |
| 正印格 | 月令正印 | 喜清纯，忌财星破印 |
| 偏印格 | 月令偏印 | 同上 |
| 食神格 | 月令食神 | 喜泄秀，需印星制衡 |
| 伤官格 | 月令伤官 | 喜泄秀，忌官杀混杂 |
| 正财格 | 月令正财 | 喜身强能任 |
| 偏财格 | 月令偏财 | 同上 |
| 建禄/月劫 | 月令比肩/劫财 | 喜官杀为用 |

### 2.4 用神喜忌

原则：身旺用克泄耗（官杀/食伤/财），身弱用生扶（印/比劫）。

### 2.5 五段式分析结构

1. **开篇**：大师风格化的开场语，融入八字基本信息
2. **总论**：日主定位→旺衰格局→十神配置→用神喜忌→大运趋势→总体建议
3. **专论**：按分析类型展开（全盘/财富/天赋/反内耗/正缘），含因果链分析
4. **经典引用**：大师经典著作引文 + 命理验证
5. **结语**：大师风格化的总结与建议

## 四、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `analyze(masterId, analysisType, bazi, gender)` | 大师ID + 分析类型 + 八字数据 + 性别 | 五段式分析对象 | 单大师风格分析 |
| `batchAnalyze(masterIds, compositeData, question)` | 大师ID数组 + 合参结果 + 问题 | 大师点评数组 | 多术数组合蒸馏 |
| `MASTERS` | - | 34位大师数据 | 大师数据只读 |
| `ANALYSIS_TYPES` | - | 分析类型配置 | 5种分析类型 |

### 分析类型

| 类型 | 标识 | 聚焦 |
|------|------|------|
| 全盘分析 | `full` | 整体命局 |
| 财富分析 | `wealth` | 财运 |
| 天赋分析 | `talent` | 天赋 |
| 反内耗 | `balance` | 精神内耗 |
| 正缘分析 | `love` | 姻缘 |

### analyze 返回结构

```javascript
{
  opening: string,    // 开篇
  overview: string,   // 总论（六段式：日主→旺衰→十神→格局→用神→总体）
  specialty: string,  // 专论（按分析类型，含因果链）
  quote: string,      // 经典引用
  closing: string     // 结语
}
```

### batchAnalyze 返回结构

```javascript
[{
  id: string,          // 大师ID
  name: string,        // 大师名称
  title: string,       // 称号
  era: string,         // 朝代
  avatar: string,      // 头像emoji
  style: string,       // 风格描述
  commentary: string   // 点评内容
}]
```
