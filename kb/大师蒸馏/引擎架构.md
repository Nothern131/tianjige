# 天机阁 · 大师蒸馏引擎（v2.0）- 引擎架构

**文件**：`static/js/masters-engine.js` + `static/js/components/masters.js`

## 概述
大师蒸馏引擎是天机阁第7层核心模块，模拟34位古今命理大师的断命风格，基于八字命盘数据生成个性化五段式分析。所有算法纯前端运行，零API调用。

## 核心模块

### 1. 五行基础（五行与天干地支）
| 类型 | 数据 |
|------|------|
| 天干 | 甲乙丙丁戊己庚辛壬癸（10个） |
| 地支 | 子丑寅卯辰巳午未申酉戌亥（12个） |
| 五行 | 木火土金水（5个） |
| 阴阳 | 天干阴阳：甲丙戊庚壬阳 / 乙丁己辛癸阴 |
| 生克 | WX_SHENG（生我）、WX_KE（克我）、WX_SHENG_BY（我生）、WX_KE_BY（我克） |

### 2. 十神映射系统（v2.0 新增）
**核心数据结构**：`SHISHEN_MAP`（5层映射）

```javascript
var SHISHEN_MAP = {
  木: {
    shengWo: { yin: '正印', yang: '偏印' },   // 生我者
    woSheng: { yin: '食神', yang: '伤官' },   // 我生者
    keWo: { yin: '正官', yang: '七杀' },     // 克我者
    woKe: { yin: '正财', yang: '偏财' },     // 我克者
    tongWo: { yin: '劫财', yang: '比肩' }    // 同我者
  },
  // 火、土、金、水同理...
};
```

**十神详细解读**（`SHISHEN_DESC`）：
- 正印：仁慈善良，聪慧好学，有贵人相助，主学识、名誉、母亲、长辈
- 偏印：领悟力强，独辟蹊径，有特殊才能，主偏门学问、继母、非正统
- 比肩：独立自主，自尊心强，朋友多助，主兄弟姐妹、同辈、竞争
- 劫财：热情豪爽，社交能力强，但易破财，主朋友、合作、花费
- 食神：温和宽厚，有口福，才艺出众，主饮食、艺术、子女、享受
- 伤官：聪明机智，才华横溢，但锋芒毕露，主技艺、口才、创新、叛逆
- 正财：勤俭务实，财运稳定，主正职收入、妻子、固定资产
- 偏财：慷慨大方，财运起伏，主副业收入、意外之财、父亲、投资
- 正官：正直守法，有责任感，主事业、官职、丈夫、纪律
- 七杀：果断刚毅，有魄力，但压力大，主竞争、权力、挑战、小人

**十神吉凶分类**（`SHISHEN_JIXIONG`）：
- 吉：正印、食神、正财、正官
- 平：偏印、比肩、劫财、伤官
- 凶：七杀

### 3. 旺衰判断（v2.0 新增）
综合三个维度判断日主旺衰：
1. **月令本气**（权重最高）：月支对应的天干五行，与日主五行比较
2. **四柱生扶**：年、月、时柱天干地支是否生扶日主
3. **五行数量**：四柱中与日主同五行的数量

输出等级：旺 → 偏旺 → 中和 → 偏弱 → 弱

### 4. 格局分析（v2.0 新增）
根据月令本气与日主的关系识别9种格局：

| 格局 | 判断条件 |
|------|----------|
| 正官格 | 月令克日主，阴阳异性 |
| 七杀格 | 月令克日主，阴阳同性 |
| 正印格 | 月令生日主，阴阳异性 |
| 偏印格 | 月令生日主，阴阳同性 |
| 食神格 | 日主生月令，阴阳同性 |
| 伤官格 | 日主生月令，阴阳异性 |
| 正财格 | 日主克月令，阴阳异性 |
| 偏财格 | 日主克月令，阴阳同性 |
| 建禄格 | 月令与日主同五行 |

**成格条件**：用神得力、五行流通、无严重冲克  
**败格条件**：用神被克、忌神猖獗、冲克严重

### 5. 用神喜忌（v2.0 新增）
- **用神**：对日主最有利的五行（平衡旺衰、辅助格局）
- **喜神**：辅助用神的五行
- **忌神**：对日主不利的五行

### 6. 大师数据（34位）
每位大师包含：
- `id`、`name`（名称）、`title`（称号）、`era`（朝代）、`category`（流派）
- `avatar`（头像）、`style`（风格描述）、`pronouns`（自称）
- `openingTemplates` / `quoteTemplates` / `closingTemplates`（多模板随机选择）

### 7. 分析生成流程
```
八字命盘输入
    ↓
日主定位（日柱天干+五行+阴阳）
    ↓
旺衰判断（月令+四柱生扶+五行数量）
    ↓
格局识别（月令本气判断9种格局）
    ↓
用神推导（基于旺衰+格局）
    ↓
用户选择大师 + 分析类型（总论/财富/天赋/反内耗/正缘）
    ↓
模板填充：
  1. 填充总论占位符（日主、旺衰、格局、用神等）
  2. 填充十神配置（四柱天干→十神映射）
  3. 填充专项分析段落（财富/天赋等）
  4. 大师个性化替换（自称、语气、引用风格）
    ↓
五段式输出：开场 → 总论 → 专论 → 经典引用 → 结语
```

## 五段式分析结构

### 1. 开场（Opening）
- 大师标志性问候语
- 基于日主五行和旺衰陈述基本判断
- 使用大师特有语气词（"老夫"、"为师"、"山人"等）

### 2. 总论（Overview）— v2.0 六段式
| 段落 | 内容 |
|------|------|
| ①日主定位 | 日柱天干 + 五行 + 阴阳属性 |
| ②旺衰格局 | 日主旺衰状态 + 格局名称 |
| ③十神配置 | 四柱十神分布详解（年干/月干/日主/时干） |
| ④用神喜忌 | 推荐用神、喜神，列出忌神 |
| ⑤大运趋势 | 当前大运和未来趋势 |
| ⑥总体建议 | 综合性的命理指导 |

### 3. 专论（Specialty）— v2.0 详细展开
按分析类型展开，每段包含十神配置 + 具体分析 + 建议：

| 分析类型 | 专论内容 |
|----------|----------|
| 财富（wealth） | 财星分析 + 财运趋势 + 理财建议 + 十神配置 |
| 天赋（talent） | 食伤分析 + 才华方向 + 发展建议 + 十神配置 |
| 反内耗（anti-internal-friction） | 压力来源 + 内耗根因 + 化解方法 + 十神配置 |
| 正缘（soulmate） | 官星/财星分析 + 缘分特征 + 时间窗口 + 十神配置 |

### 4. 经典引用（Quote）
- 引用大师经典著作中的相关语句
- 与当前命盘分析内容呼应

### 5. 结语（Closing）
- 大师标志性结束语
- 总结核心观点
- 鼓励或警示

## 技术要点

### 模板填充系统
- **占位符**：`{日主}`、`{日主五行}`、`{旺衰}`、`{格局}`、`{用神}`、`{喜神}`、`{忌神}`、`{十神配置}` 等
- **代词系统**：每位大师有专属自称（鬼谷子-"老夫"、袁天罡-"山人"、刘伯温-"某"等）
- **多层随机**：每位大师多种开场/引用/结语模板，随机选择避免重复

### 代码保护
- IIFE 包裹，防止全局变量污染
- 与 `EngineRegistry` 统一注册（通过 `EngineRegistry.register('masters', mastersEngine)`）
- 纯前端，零外部依赖
