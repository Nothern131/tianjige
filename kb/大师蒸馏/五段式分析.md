# 天机阁 · 大师蒸馏 - 五段式分析（UI组件）

**文件**：`static/js/components/masters.js`

## 概述
UI组件负责人机交互和结果展示，负责调用 `masters-engine.js` 的分析函数，生成五段式分析并渲染到页面。

## 组件功能

### 1. 大师选择器
- **布局**：网格布局（8列），展示34位大师头像和名称
- **每行8位**：4行完整 + 最后2位单独一行
- **交互**：点击切换当前选中的大师，更新风格描述

### 2. 分析类型切换
| 类型 | 描述 | 对应按钮 |
|------|------|----------|
| 总论 | 命盘格局 · 一生通览 | 总论 |
| 财富 | 财运分析 · 富贵贫贱 | 财富 |
| 天赋 | 才华禀赋 · 天命所归 | 天赋 |
| 反内耗 | 心神安顿 · 内耗化解 | 反内耗 |
| 正缘 | 姻缘分析 · 良缘佳期 | 正缘 |

### 3. 分析结果展示
- **五段式分段渲染**：
  1. 开场 → `h3` + 段落
  2. 总论 → `h3` + 多段分析
  3. 专论 → `h3` + 专项分析
  4. 经典引用 → `h3` + 引用段落
  5. 结语 → `h3` + 结语段落
- **风格标签**：显示当前大师的流派、朝代、风格描述

### 4. 风格展示区
- 大师名称、称号、朝代、流派
- 风格描述（如：纵横捭阖，言简意赅，多用比喻，以阴阳开阖之理喻人事）

## 渲染流程

```
用户点击"分析"按钮
    ↓
mastersEngine.analyze(masterId, analysisType, baziData)
    ↓
返回五段式分析对象：{ opening, overview, specialty, quote, closing }
    ↓
UI组件按段落渲染：
  - opening + 大师风格标签
  - overview + 详细总论段落
  - specialty + 专项分析段落
  - quote + 经典引用
  - closing + 结语
    ↓
页面显示完整五段式分析报告
```

## 模板系统

### 大师模板结构（在 `masters-engine.js` 中定义）

每位大师对象包含：
```javascript
{
  id: 'guiguzi',
  name: '鬼谷子',
  title: '纵横家鼻祖',
  era: '战国',
  category: '六爻',
  avatar: '🧙',
  style: '纵横捭阖，言简意赅，多用比喻，以阴阳开阖之理喻人事',
  pronouns: '老夫',           // 自称
  phrase: '捭阖之道，阴阳之机', // 标志性语句
  openingTemplates: [...],     // 开场模板数组（随机选择）
  quoteTemplates: [...],       // 引用模板数组（随机选择）
  closingTemplates: [...]      // 结语模板数组（随机选择）
}
```

### 填充规则
1. **开场**：从 `openingTemplates` 中随机选择1条，填充 `{日主}`、`{日主五行}`、`{旺衰}` 等占位符
2. **总论**：六段式结构化输出，填充详细分析内容
3. **专论**：根据分析类型从 `generateDetailedSpecialty` 生成多段内容，填充十神配置和专项分析
4. **引用**：从 `quoteTemplates` 中随机选择1-2条，根据流派适当调整
5. **结语**：从 `closingTemplates` 中随机选择1条

## 代码保护

- IIFE 包裹 `components/masters.js`，防止全局变量污染
- 通过 `EngineRegistry.register('masters', MastersComponent)` 统一注册
- 页面加载时自动初始化大师选择器和分析按钮

## 与引擎层的交互

```
UI组件 (masters.js)
    ↓ 调用 analyze()
引擎层 (masters-engine.js)
    ↓ 返回分析结果
UI组件 → 渲染到页面
```
