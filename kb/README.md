## 使用方式

### 作为工作源

所有引擎功能变更应**首先**在此知识库位置编写文档，保持最新、最完整的技术记录。

### 同步到 Obsidian

由于 Obsidian Vault 路径不在工作目录白名单中，自动同步受阻。建议操作：

1. **手动同步**：用户在 Obsidian 中打开对应文件，复制粘贴 `E:\天机阁\kb\` 中的内容
2. **未来自动化**：可配置 CI/CD 脚本（如 GitHub Actions）在每次 commit 后自动复制更新
