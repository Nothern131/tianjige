# 天机阁 · 引擎开发规范

> 最后更新：2026-08-02

---

## 一、引擎接口标准

每个引擎必须实现以下接口：

```javascript
global.XxxEngine = {
  // 【必须】排盘/计算主入口
  divine: function(params) { return result; },

  // 【可选】分析
  analyze: function(result) { return analysis; },

  // 【可选】解释
  explain: function(result) { return explanation; }
};
```

## 二、参数规范

### 2.1 divine(params)

`params` 为对象，字段根据引擎类型而定：

| 引擎类型 | 必需参数 | 可选参数 |
|----------|----------|----------|
| 八字 | birthYear, birthMonth, birthDay, birthHour | gender |
| 六爻 | -（自动起卦） | question |
| 梅花 | -（自动起卦） | numbers, question |
| 奇门 | -（当前时辰） | question |
| 太乙 | -（当前年份） | year |
| 诸葛 | text（三字测事） | - |
| 周公 | dream（梦境文本） | - |
| 大六壬 | -（当前时辰） | question |
| 紫微 | birthYear, birthMonth, birthDay, birthHour | gender |
| 风水 | sitting, facing, buildYear | currentYear |

### 2.2 result 返回格式

```javascript
{
  // 基础信息
  method: '引擎名称',
  timestamp: '2026-08-02T...',

  // 核心数据（引擎特定）
  data: { ... },

  // 分析结果（可选）
  analysis: {
    score: 85,          // 综合评分 0-100
    level: '吉',        // 等级
    summary: '...',     // 总结
    details: [...]      // 详细分析
  },

  // 解释文本（可选）
  explanation: '...'
}
```

## 三、代码规范

### 3.1 文件结构

```javascript
/**
 * 天机阁 · XXX引擎 v1
 * 纯前端，零API
 */
(function(global) {
  'use strict';

  /* ========== 一、常量定义 ========== */
  var CONST = { ... };

  /* ========== 二、核心计算 ========== */
  function coreCalc(params) { ... }

  /* ========== 三、分析评估 ========== */
  function analyze(data) { ... }

  /* ========== 四、公开 API ========== */
  global.XxxEngine = {
    CONST: CONST,
    divine: function(params) { ... }
  };

})(typeof window !== 'undefined' ? window : this);
```

### 3.2 命名规范

- 引擎全局对象：`XxxEngine`（PascalCase）
- 常量：`UPPER_SNAKE_CASE`
- 函数：`camelCase`
- 私有函数：`_privateFunction`（下划线前缀）

### 3.3 常量导出

引擎内部的常量数据应导出到全局对象，供组件引用：

```javascript
global.FengshuiEngine = {
  MOUNTAINS_24: MOUNTAINS_24,   // 二十四山
  STARS: STARS,                  // 九星数据
  GONG_NAMES: GONG_NAMES,       // 九宫名称
  // ...
};
```

## 四、测试规范

### 4.1 冒烟测试

每个引擎至少包含：
- 默认参数调用 `divine()` 不报错
- 返回结果包含必要字段
- 边界值测试（极值年份、空参数）

### 4.2 测试文件

- 浏览器测试：`test_all_engines.html`
- Node.js 测试：`test-engines-node.js`

## 五、版本管理

### 5.1 版本号格式

`v{major}.{minor}`

- major：架构变更、接口不兼容
- minor：功能新增、bug 修复
