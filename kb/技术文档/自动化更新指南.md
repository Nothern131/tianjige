# 天机阁 · 知识库自动化更新指南

## 问题说明
知识库位于 `E:\天机阁\kb\`（工作目录，可写），但目标 Obsidian Vault 路径 `C:\Users\lzb17\Documents\Obsidian Vault\天机阁-` 不在系统写权限白名单内，导致自动化写入失败。

## 方案一：PowerShell 同步脚本（推荐）

创建同步脚本 `sync-kb.psht`，从 `E:\天机阁\kb\` 复制到 Obsidian 目录：

```powershell
#!/usr/bin/env pwsh
# 天机阁知识库同步脚本
# 运行方式：.\sync-kb.ps1

$source = "E:\天机阁\kb\"
$destination = "C:\Users\lzb17\Documents\Obsidian Vault\"

# 检查源目录是否存在
if (-not (Test-Path $source)) {
    Write-Error "源目录不存在: $source"
    exit 1
}

# 复制所有文件
Copy-Item -Path "$source\*" -Destination $destination -Recurse -Force -ErrorAction Stop

Write-Host "✅ 同步成功！" -ForegroundColor Green
Write-Host "源: $source"
Write-Host "目标: $destination"
```

**定时任务**（可选）：使用 Windows Task Scheduler 每天定时执行，或在 Git commit 后通过 hook 触发。

## 方案二：Robocopy 批处理

```batch
@echo off
robocopy "E:\天机阁\kb\" "C:\Users\lzb17\Documents\Obsidian Vault\" /E /NFL /NDL /NJH /NJS /R:1 /W:1
echo 同步完成。
```

## 方案三：Obsidian 插件方式

在 Obsidian 中使用以下插件实现双向同步：

1. **Obsidian Sync**：官方同步插件，可设置同步文件夹
2. **Local Backup**：备份插件，可将 `E:\天机阁\kb\` 设为备份源
3. **Templater** 或 **Dataview**：通过脚本动态更新文件

## 方案四：Git + GitHub Pages

将知识库托管到 GitHub，通过 Pages 服务访问：

```bash
# 初始化 Git 仓库
cd E:\天机阁\kb\
git init
git add .
git commit -m "Initial commit: 天机阁知识库 v1.0"
git remote add origin <github-repo-url>
git push -u origin main
```

然后在 GitHub Pages 启用，知识库可通过网页访问，Obsidian 通过 `Git` 插件同步。

## 维护流程

1. **引擎开发**：在对应模块下创建 `X.X_发布说明.md` 文档，详细记录变更、测试、代码链接
2. **更新总索引**：在 `项目总览.md` 的"引擎版本更新记录"部分添加新版本条目
3. **运行同步脚本**：执行 `sync-kb.ps1` 将内容复制到 Obsidian 目录
4. **在 Obsidian 中打开**：查看合并效果，手动调整格式（如链接格式）

## 注意事项

- 同步脚本需以**管理员权限**运行（涉及跨目录写入）
- 文件名需匹配（`项目总览.md` → `天机阁-项目总览.md`），可能需要在脚本中添加重命名逻辑
- 中文路径需确保文件系统编码支持 UTF-8
- 备份原始文件后再同步，防止覆盖错误
