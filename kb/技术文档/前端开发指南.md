## 三、开发规范

### 3.1 代码风格

- 使用 `'use strict'` 严格模式
- IIFE 包裹，避免全局污染：`(function(global) { ... })(window)`
- 变量声明使用 `var`（兼容性考虑）
- 缩进：2 空格
- 注释：中文，关键逻辑注释"为什么"

### 3.2 引擎开发

创建新引擎的步骤：

1. 创建 `static/js/xxx-engine.js`
2. 使用 IIFE 包裹，暴露 `global.XxxEngine`
3. 实现 `divine(params)` 主入口方法
4. 在 `engine-registry.js` 注册
5. 创建 `static/js/components/xxx.js` 组件
6. 在 `app.js` 路由注册
7. 在 `index.html` 引入脚本和导航

### 3.3 组件开发

```javascript
// 标准组件模板
(function(global) {
  'use strict';

  function render(container) {
    // 1. 构建 HTML
    container.innerHTML = '...';

    // 2. 绑定事件
    bindEvents(container);

    // 3. 初始化
    init(container);
  }

  function bindEvents(container) { /* ... */ }
  function init(container) { /* ... */ }

  // 暴露渲染函数
  global.renderXxxComponent = function() {
    var div = document.createElement('div');
    render(div);
    return div;
  };
})(window);
```

### 3.4 样式规范

- 新组件使用命名空间前缀（如 `fs-` 风水组件）
- 复用全局样式类：`glass-card`、`btn-gold`、`page-title` 等
- 响应式断点：`@media (max-width: 768px)`
- 颜色使用 CSS 变量，不硬编码

### 3.5 路由注册

在 `app.js` 的 `routes` 对象中添加：

```javascript
xxx: function() { return renderXxxComponent(); }
```

在 `index.html` 侧边栏导航添加：

```html
<a href="#/xxx" class="nav-link" data-route="/xxx">
  <span class="nav-icon">🔮</span>模块名称
</a>
```

## 四、调试技巧

### 4.1 强制刷新

修改 JS/CSS 后，使用 `Ctrl+F5` 强制刷新绕过缓存。

### 4.2 语法检查

```bash
node --check static/js/components/fengshui.js
```

### 4.3 浏览器控制台

- F12 打开开发者工具
- Console 面板查看 JS 错误
- Network 面板确认资源加载

## 五、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `renderXxxComponent is not defined` | JS 语法错误导致脚本未加载 | `node --check` 检查语法 |
| 页面空白 | 路由未注册或组件返回空 | 检查 app.js routes 和组件 render 函数 |
| 样式不生效 | 缓存 | Ctrl+F5 强制刷新 |
| 罗盘变形 | canvas 宽高不一致 | 使用 `Math.min(w, h)` 保证正方形 |
