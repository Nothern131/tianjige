# 天机阁 · 代码保护机制

> 最后更新：2026-08-02
> 适用文件：`ep1-fengshui.html`、`architecture.html`

---

## 一、概述

天机阁采用前端代码保护策略，防止普通用户通过浏览器开发者工具查看源码、复制内容或调试逻辑。保护机制覆盖三个层面：右键菜单、快捷键、控制台。

> **设计原则**：保护是"防君子不防小人"级别的，不依赖服务端校验，纯前端拦截。专业开发者仍可通过 curl/wget 等方式获取源码，但普通用户的操作门槛已足够。

---

## 二、保护层级

### 2.1 右键菜单拦截

```javascript
document.addEventListener('contextmenu', function(e) {
  e.preventDefault();
  return false;
});
```

- **拦截内容**：右键菜单（"查看源代码"、"检查元素"等入口）
- **例外**：风水体验页中，上传区域（`#uploadZone`）和罗盘 Canvas（`#compassCanvas`）允许拖拽操作

### 2.2 快捷键拦截

```javascript
document.addEventListener('keydown', function(e) {
  // F12 开发者工具
  if (e.keyCode === 123) { e.preventDefault(); return false; }
  // Ctrl+Shift+I / J / C（开发者工具、控制台、元素检查）
  if (e.ctrlKey && e.shiftKey && (e.keyCode === 73 || e.keyCode === 74 || e.keyCode === 67)) {
    e.preventDefault(); return false;
  }
  // Ctrl+U（查看源代码）
  if (e.ctrlKey && e.keyCode === 85) { e.preventDefault(); return false; }
  // Ctrl+S（保存页面）
  if (e.ctrlKey && e.keyCode === 83) { e.preventDefault(); return false; }
});
```

| 快捷键 | 拦截内容 |
|--------|----------|
| F12 | 开发者工具 |
| Ctrl+Shift+I | 开发者工具（Chrome/Firefox） |
| Ctrl+Shift+J | 控制台（Chrome） |
| Ctrl+Shift+C | 元素检查（Chrome） |
| Ctrl+U | 查看页面源代码 |
| Ctrl+S | 保存网页 |

### 2.3 控制台清理

```javascript
// 初始化时清空控制台
console.clear();

// 每3秒自动清空，防止通过控制台调试
setInterval(function() { console.clear(); }, 3000);
```

- **品牌输出**：清空后会输出天机阁品牌信息（版本号、模块名、版权声明），但不会暴露任何内部逻辑
- **定时清理**：3秒间隔自动清空，即使手动打开控制台也会被持续清屏

### 2.4 文本选择/拖拽拦截

```javascript
document.addEventListener('dragstart', function(e) { e.preventDefault(); return false; });
document.addEventListener('selectstart', function(e) { e.preventDefault(); return false; });
```

- 禁止文本选择，防止 Ctrl+A → Ctrl+C 复制内容
- 禁止拖拽，防止拖拽到外部应用

## 三、适用文件

| 文件 | 保护级别 | 说明 |
|------|----------|------|
| `ep1-fengshui.html` | 完整保护 | 右键+F12+快捷键+控制台+选择+拖拽 |
| `architecture.html` | 完整保护 | 右键+F12+快捷键+控制台+选择+拖拽 |
| `index.html` | 无保护 | 首页为公开入口，不拦截 |

---

## 四、局限性

1. **浏览器兼容性**：`keyCode` 已废弃（推荐 `KeyboardEvent.code`），但当前实现覆盖主流浏览器
2. **Firefox 例外**：部分 Firefox 版本的开发者工具快捷键可能无法完全拦截
3. **curl/wget**：纯前端保护无法阻止 HTTP 请求直接获取源码
4. **浏览器扩展**：部分开发者工具扩展可能绕过拦截
5. **移动端**：移动端浏览器无 F12 等效快捷键，保护主要针对桌面端

## 五、添加保护到新页面

如需为新页面添加保护，在 `<script>` 标签末尾插入以下代码块：

```javascript
// === 代码保护 ===
document.addEventListener('contextmenu', function(e) { e.preventDefault(); return false; });
document.addEventListener('dragstart', function(e) { e.preventDefault(); return false; });
document.addEventListener('selectstart', function(e) { e.preventDefault(); return false; });
console.clear();
console.log('%c 天机阁 %c [模块名] %c vX.X ',
  'font-family:"Noto Serif SC",serif;font-size:20px;color:#d4bb7c;',
  'font-size:11px;color:#8a8576;');
console.log('%c 模块描述 ','font-size:11px;color:#4a9a8c;');
console.log('%c (c) 天机阁 | 保留所有权利 ','font-size:9px;color:#4a4640;');

document.addEventListener('keydown', function(e) {
  if (e.keyCode === 123) { e.preventDefault(); return false; }
  if (e.ctrlKey && e.shiftKey && (e.keyCode === 73 || e.keyCode === 74 || e.keyCode === 67)) {
    e.preventDefault(); return false;
  }
  if (e.ctrlKey && e.keyCode === 85) { e.preventDefault(); return false; }
  if (e.ctrlKey && e.keyCode === 83) { e.preventDefault(); return false; }
});

setInterval(function() { console.clear(); }, 3000);
```
