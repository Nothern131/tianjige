## 三、引擎架构

### 3.1 引擎注册机制

所有引擎通过 `engine-registry.js` 统一注册：

```javascript
Tianjige.EngineRegistry.register({
  id: 'bazi',
  name: '八字排盘',
  category: 'natal',      // natal | instant | spacetime | text
  engine: BaziEngine,
  component: renderBaziComponent
});
```

### 3.2 引擎分类

| 分类 | 类型 | 引擎 |
|------|------|------|
| 命盘类（natal） | 基于出生时间 | 八字、紫微 |
| 即时类（instant） | 当前时间起卦 | 六爻、梅花、诸葛 |
| 时空类（spacetime） | 时空模型 | 奇门、太乙、大六壬、风水 |
| 文本类（text） | 文本解析 | 周公解梦 |

### 3.3 引擎接口规范

每个引擎暴露为全局对象（IIFE），核心方法：

```javascript
// 排盘/计算主入口
Engine.divine(params) → result

// 可选：分析
Engine.analyze(result) → analysis

// 可选：解释
Engine.explain(result) → explanation
```

## 四、组件架构

### 4.1 组件渲染流程

```
路由 hashchange → app.js navigateTo()
  → routes[page]() → renderXxxComponent()
  → 创建 DOM 元素 → 挂载到 page-container
```

### 4.2 组件规范

每个组件暴露一个渲染函数：

```javascript
// 方式1：返回 DOM 元素
global.renderBaziComponent = function(params) {
  var div = document.createElement('div');
  // 构建 UI ...
  return div;
};

// 方式2：渲染到容器
global.FengshuiComponent = {
  render: function(container) {
    // 构建 UI 到 container ...
  }
};
```
