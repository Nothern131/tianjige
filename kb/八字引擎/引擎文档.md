# 八字引擎 v1 · 引擎文档

> 文件：`static/js/bazi-engine.js` | 流派：徐子平·子平术 | 全局：`BaziEngine`

## 一、概述

八字（四柱命理）引擎，基于**徐子平子平术**体系。纯前端算法，零 API 调用。根据出生年月日时排四柱八字，计算十神、五行、纳音、神煞，并生成七大分析维度。

## 二、核心算法

### 2.1 排盘（paipan）

| 柱 | 算法 | 说明 |
|----|------|------|
| 年柱 | 以1900年庚子年为基准，计算年干支 | `calcYearGZ(year)` |
| 月柱 | 五虎遁（年上起月）+ 立春为界 | `calcMonthGZ(yearGan, monthZhi)` |
| 日柱 | 以1900-01-01甲戌日为基准，计算累计天数 | `calcDayGZ(year, month, day)` |
| 时柱 | 五鼠遁（日上起时）+ 时辰地支 | `calcHourGZ(dayGan, hour)` |

### 2.2 十神计算

基于**日干与他干**的五行生克+阴阳异同，生成十神关系：
- 同我：比肩（阴阳同）/ 劫财（阴阳异）
- 生我：正印（阴阳异）/ 偏印（阴阳同）
- 我生：食神（阴阳同）/ 伤官（阴阳异）
- 克我：正官（阴阳异）/ 七杀（阴阳同）
- 我克：正财（阴阳异）/ 偏财（阴阳同）

### 2.3 大运系统

- **顺逆排**：阳年男/阴年女顺排，阴年男/阳年女逆排
- **起运年龄**：出生日到节气天数 ÷ 3
- **大运干支**：从月柱开始，每十年一柱，共8柱
- **运势评估**：基于天干地支与日主生克关系 + 喜用神忌神加权

## 三、公开 API

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `paipan(year, month, day, hour)` | 公历年月日时 | 四柱八字对象 | 排盘 |
| `wealth(bazi)` | 八字对象 | { analysis, score, highlights } | 财富分析 |
| `talent(bazi)` | 八字对象 | { analysis, score, highlights } | 天赋分析 |
| `balance(bazi)` | 八字对象 | { analysis, score, highlights } | 反内耗/五行平衡 |
| `lifeline(bazi, gender, birthYear, birthMonth, birthDay)` | 八字+性别+出生日 | 人生K线+大运 | 人生K线 |
| `monthly(bazi)` | 八字对象 | { analysis, months } | 流月运势 |
| `love(bazi, gender)` | 八字+性别 | { analysis, score } | 正缘分析 |
| `dateSelect()` | 无 | { analysis, good_dates, bad_dates } | 择日 |
| `getShiShen(dayGan, otherGan)` | 两天干 | 十神名称 | 单对十神 |
| `getPillarShiShen(dayGan, pillars)` | 日干+四柱 | 四柱十神详情 | 四柱十神 |
| `countWuxing(pillars)` | 四柱 | 五行计数 | 五行统计 |

## 四、分析方法

| 分析维度 | 核心逻辑 | 评分范围 |
|----------|----------|----------|
| 财富 | 财星数量 + 食伤生财 + 财库检查 | 30-95 |
| 天赋 | 食伤+印星+官杀组合 | 30-95 |
| 反内耗 | 五行平衡度 + 喜用神忌神 + 调候 | 0-100 |
| 人生K线 | 8步大运 + 流年 + 运势评分 | 15-95 |
| 正缘 | 配偶星 + 配偶宫冲合 | 30-95 |

## 六、常量体系

- **天干五行**：甲木/乙木/丙火/丁火/戊土/己土/庚金/辛金/壬水/癸水
- **地支五行**：子水/丑土/寅木/卯木/辰土/巳火/午火/未土/申金/酉金/戌土/亥水
- **地支藏干**：完整12地支藏干映射
- **调候用神**：10天干 × 12月令调候表
- **纳音**：60甲子纳音全表
- **节气**：12节气近似日期表
