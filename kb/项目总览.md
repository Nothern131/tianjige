# 天机阁 · 项目总览（知识库中心版）

> **注**：本文件位于 `E:\天机阁\kb\` 为主知识源，Obsidian Vault 中的对应文件请通过此源同步。

## 项目简介
天机阁是一个纯前端占卜算法平台，集成 10 种术数引擎 + 领域分析 + 合参引擎 + 34 位大师蒸馏，所有算法本地运行，零 API 调用。

## 技术架构（7 层）

| 层级 | 内容 |
|------|------|
| 第1层·用户入口 | 选择术数模块 → 输入参数/问题 |
| 第2层·路由分发 | app.js · Hash 路由 |
| 第3层·组件层 | 10个术数组件 + 大师蒸馏 + 合参 |
| 第4层·引擎层 | EngineRegistry 统一注册：命盘类/即时类/时空类/文本类 |
| 第5层·领域分析 | domain-analysis.js：事业、感情、财运、健康、学业、家庭、社交、出行、综合 |
| 第6层·合参引擎 | 评分提取 → 加权融合 → 融洽磨合 |
| 第7层·大师蒸馏 & 输出 | 34位大师风格复刻 → 五段式分析输出<br>详细文档：[[大师蒸馏/引擎架构]] |

## 引擎版本更新记录

### 算法增强 · 双面性分析 v1（2026-08-03）

**核心理念**：术数在于趋吉避凶，世间万物皆有阴阳两面。吉非纯吉，凶非纯凶。每个结论必须包含：优势面、风险面、转化关键、时机建议。

**新增模块**：
- ✅ **duality-analyzer.js**：双面性分析共享模块，提供五行生克双面解读库、通用双面性生成器、输入校验、错误恢复等工具函数

**引擎增强**：
- ✅ **六爻引擎**：`_getJudgment` 重写为四层分析（世爻核心×双面→世应博弈→动爻格局→变卦指引→六兽加持），`_getAdvice` 重写为五层建议（世爻趋吉避凶→世应调和→动爻应对→六兽行动指南→变卦应对→心法），覆盖 25 种世应/动爻/六亲/六兽交叉组合
- ✅ **梅花易数引擎**：`calcShengKe` 增加全部五种体用关系的双面解读（吉面/凶面/转化/时机），`generateInterpretation` 重写为六段式（本卦→互卦→变卦→三卦联动→体用双面→趋吉避凶策略），新增 `analyzeThreeGuaPath` 和 `buildMeihuaStrategy` 辅助函数
- ✅ **domain-analysis.js**：新增 `buildLiuyaoDualityAdvice` 和 `buildMeihuaDualityAdvice` 函数，为六爻和梅花的每个事域（事业/感情/财运/健康/学业）提供双面视角趋吉避凶分析

**八字引擎**（前期已完成）：
- ✅ 财富分析：财星基础判断→多因素交叉分析（食伤生财/比劫夺财/官杀护财/印星影响/财库）→冲突信号→趋吉避凶→综合评分
- ✅ 天赋分析、反内耗分析同样加入多因素交叉和趋吉避凶

### 大师蒸馏引擎 v2.0（2026-07-29）

**核心新增**：
- ✅ **十神计算系统**：`SHISHEN_MAP` 五层映射（生我/我生/克我/我克/同我 × 阴阳），`SHISHEN_DESC` 详细解读
- ✅ **旺衰判断**：综合月令本气（权重最高）、四柱生扶、五行数量，输出：旺/偏旺/中和/偏弱/弱
- ✅ **格局分析**：正官格、七杀格、正印格、偏印格、食神格、伤官格、正财格、偏财格、建禄格 9种格局识别 + 成败条件
- ✅ **用神喜忌**：基于旺衰和格局推导用神、喜神、忌神
- ✅ **详细总论（六段式）**：日主定位 → 旺衰格局 → 十神配置 → 用神喜忌 → 大运趋势 → 总体建议
- ✅ **详细专论**：按分析类型展开（财富/天赋/反内耗/正缘），含十神配置、专项分析、具体建议
- ✅ 新增函数：`generateDetailedOverview()` / `generateDetailedSpecialty()`

**文档详情**：[大师蒸馏/引擎架构.md](大师蒸馏/引擎架构.md) | [大师蒸馏/v2.0_发布说明.md](大师蒸馏/v2.0_发布说明.md)

### 风水引擎 v3.0（2026-07-29）

**核心新增**：
- ✅ **拼户型建造器**：9种房间类型（客厅/主卧/次卧/厨房/餐厅/卫生间/书房/阳台/玄关）+ 拖拽放置
- ✅ **多网格尺寸支持**：3×3、4×3、4×4、5×4、5×5 五种尺寸动态切换，通过 CSS 变量 `--grid-cols` / `--grid-rows` 控制
- ✅ **动态网格生成**：`regenerateGrid(cols, rows)` 函数根据选择的行列数重建网格单元格，通过 `(col*3/cols, row*3/rows)` 映射到九宫格宫殿索引
- ✅ **罗盘交互重构**：`pointer-events:none` 视觉化 → 旋转拖拽迁移至 `gridWrapper` 父容器；外环区域（42%~51%半径）触发旋转，网格区域（0~38%半径）不拦截
- ✅ **布局优化**：网格大小选择器居中置于 Canvas 上方，`.grid-container` 改为纵向排列
- ✅ **测试结果**：全部6项测试通过（网格切换、9种房间放置、随机布局、开始排盘、清空房间、5×5网格+排盘）

**文档详情**：[风水引擎/体验页-v3.0.md](风水引擎/体验页-v3.0.md) | [风水引擎/v3.0_发布说明.md](风水引擎/v3.0_发布说明.md)
