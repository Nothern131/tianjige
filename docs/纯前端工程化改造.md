2. 删除 Python 依赖（`app.py`、`config.py`、`api/`、`core/`、`tests/`、`vercel.json`、`requirements.txt`）
3. 删除无用的 `api.js`
4. 加入 ESLint + Prettier 代码质量检查
5. 更新 GitHub Actions 改为 `npm run build` 后推 `dist/`
6. 更新相关文档（`前端开发指南.md`、`架构设计.md`、`README.md`）

## 四、风险提示

1. **Vite script 加载顺序**：Vite 默认按 `<script src>` 标签顺序执行，与当前 `index.html` 一致，无需改 HTML
2. **IIFE 全局变量**：Vite 不改变 IIFE 执行方式，`window.Xxx = ...` 仍生效
3. **IIFE 中 `global` 参数**：浏览器中 `global` = `window`，Vite 构建后仍正常
4. **无 ES Module 迁移**：本方案不引入 import/export，保持现有 IIFE 模式，零迁移成本
