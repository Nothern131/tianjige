# 风水引擎 · 玄空飞星

## 概述
天机阁风水引擎，基于玄空飞星风水理论，实现纯前端算法排盘。支持二十四山坐向、三元九运、九宫飞泊、年星飞布，输出九宫吉凶评估和风水建议。

## 核心算法

### 1. 三元九运
- 上元：一运（1864-1883）→ 二运 → 三运
- 中元：四运 → 五运 → 六运
- 下元：七运（1984-2003）→ 八运（2004-2023）→ 九运（2024-2043）
- 每运20年，共180年为一周期

### 2. 二十四山
```
壬 子 癸 | 丑 艮 寅 | 甲 卯 乙 | 辰 巽 巳 | 丙 午 丁 | 未 坤 申 | 庚 酉 辛 | 戌 乾 亥
```
- 每山15度，二十四山共360度
- 归属八卦：坎(壬子癸)、艮(丑艮寅)、震(甲卯乙)、巽(辰巽巳)、离(丙午丁)、坤(未坤申)、兑(庚酉辛)、乾(戌乾亥)

### 3. 九宫飞泊
- 洛书轨迹：中五 → 乾六 → 兑七 → 艮八 → 离九 → 坎一 → 坤二 → 震三 → 巽四
- 运星以中宫为运数，按洛书轨迹飞布九宫
- 山星以坐山所在宫位运星为中宫，飞布九宫
- 向星以朝向所在宫位运星为中宫，飞布九宫

### 4. 年星飞布
- 基准年1900年，中宫为1白
- 逐年递减1，超过9则归1
- 当前年星中宫 = (1 - (year - 1900)) mod 9

### 5. 宫位评估算法
每个宫位综合评估四项飞星：
- **运星**：当前元运的飞星分布
- **山星**：坐山决定的飞星（主人丁）
- **向星**：朝向决定的飞星（主财运）
- **年星**：当年流年飞星（主当年吉凶）

**评分规则**：
- 基础分：60分
- 五黄临宫：-15～-20分（大凶）
- 二黑病符：-8～-10分（凶）
- 三碧是非：-5～-6分（凶）
- 七赤破财：-5～-6分（凶）
- 八白旺财：+10～+12分（吉）
- 九紫喜庆：+8～+10分（吉）
- 一白文昌：+6～+8分（吉）
- 六白权贵：+6～+8分（吉）
- 四绿文昌：+4～+5分（中）
- 山向合十：+10分（大吉，合十效应）
- 五行生克：±5分（运星生宫为吉，克宫为凶）

**等级划分**：
- ≥80：大吉
- 65-79：吉
- 50-64：中平
- 35-49：凶
- <35：大凶

### 6. 总体评估
- 九宫评分取平均值
- 总体等级：≥75上吉 / ≥60中吉 / ≥45中平 / ≥30凶 / <30大凶

## 体验页功能

### 文件
`ep1-fengshui.html`

### 核心功能
1. **排盘参数输入**：建房年份、坐山、朝向、当前年份
2. **九宫飞星盘**：洛书九宫格展示，每宫显示运/山/向/年四星及评分
3. **总体评估**：综合评分和等级
4. **最佳/最差方位**：推荐宜忌方位
5. **九宫详表**：完整数据表格

### 户型图叠加（v2.0新增）
- 拖拽/点击上传户型图（JPG/PNG/WebP）
- Canvas绘制九宫格覆盖在户型图上
- 拖拽调整九宫格位置
- 滚轮缩放九宫格大小
- 透明度调节
- 实时显示各宫位评分和飞星信息

### 视觉风格
- 水墨粒子背景动画
- 罗盘旋转装饰
- 暗色主题 + 金色点缀
- 卡片渐变边框动效
- 淡入上浮动画

### 技术要点
- 纯前端算法，零API调用
- Canvas 2D渲染户型图叠加
- 代码保护（右键/快捷键拦截）
- 响应式布局
