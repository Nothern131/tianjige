# EP11 合参 Experience Page 设计文档

> 创建时间：2026-10-31
> 状态：待评审

## 目标

创建多术数合参独立体验页（ep11-composite.html）：选择 1-9 门术数并行推演，输出综合评分、各术明细、事域交叉、融洽磨合与融合研判。

## 边界

- 复用 `engine-registry.js`（`EngineRegistry.executeAll`）与 `composite-engine.js`（`CompositeEngine.run`）
- 不新增/修改引擎算法，只做前端展示层
- 不接入大师点评（按用户要求：大师蒸馏页不做，且各板块已有大师）
- 风水不纳入合参（注册权重 0，且输入维度独立）
- 风格与 EP1-EP10 一致（暗色 `--ink`、`--gold`、`Noto Serif SC`、玻璃卡片、stagger、`prefers-reduced-motion`、水墨粒子）

## 输入

- 出生日期 / 出生时辰 / 性别（供八字、紫微）
- 占测日期 / 占时（供奇门、太乙、大六壬，默认当天 + 巳时）
- 所问之事（可选，事域标签自动填充）
- 术数多选（9 门：八字/六爻/梅花/奇门/太乙/诸葛/解梦/大六壬/紫微），默认勾选 八字 + 六爻 + 梅花
- 勾选「周公解梦」时显示梦境描述输入（缺失则用「梦见龙飞翔」兜底并提示）

## 输出

```
02 综合评分 → 03 各术独立推演 → 04 事域交叉 → 05 融洽磨合 → 06 融合研判
```

- 综合评分：0-100 分、五星、趋势、共识标签、参与术数数量
- 各术明细：图标、名称、分数、趋势、摘要、断语、关键提示
- 事域交叉：看好/平稳/谨慎计数 + 各术洞察 + 共识文本
- 融洽磨合：总体融洽度/磨合度、两两组合融洽条、总评文本
- 融合研判：三阶段推演正文、置信度、分歧跨度
- 若部分引擎返回空结果，显式提示「X 门术数无有效结果」，不静默降级
