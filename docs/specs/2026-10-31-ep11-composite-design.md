# EP11 合参 Experience Page 设计文档

> 创建时间：2026-10-31
> 状态：待评审

## 目标

创建多术数合参独立体验页（ep11-composite.html）：最多选择 3 门术数并行推演，按命局/事占/时空分层输出，再做层内融合与命事互证。

## 边界

- 复用 `engine-registry.js`（`EngineRegistry.executeAll`）与 `composite-engine.js`（`CompositeEngine.run`）
- 不新增/修改引擎算法，只做前端展示层
- 不接入大师点评（按用户要求：大师蒸馏页不做，且各板块已有大师）
- 风水不纳入合参（注册权重 0，且输入维度独立）
- 风格与 EP1-EP10 一致（暗色 `--ink`、`--gold`、`Noto Serif SC`、玻璃卡片、stagger、`prefers-reduced-motion`、水墨粒子）

## 输入

- 出生日期 / 出生时辰 / 性别（供八字、紫微）
- 占测日期 / 占时（供奇门、太乙、大六壬，默认当天 + 巳时）
- 所问之事（可选，事域标签自动填充）
- 术数多选（9 门：八字/六爻/梅花/奇门/太乙/诸葛/解梦/大六壬/紫微），**最多 3 门**，默认勾选 八字 + 六爻 + 梅花；第 4 门拦截并提示
- 合参模式：命局合参 / 事占合参 / 命事合参 / 自定义
- 勾选「周公解梦」时显示梦境描述输入（缺失则用「梦见龙飞翔」兜底并提示）

## 输出

```
02 分层总览 → 03 分层各术推演 → 04 事域交叉 → 05 层内融洽 → 06 融合研判·命事互证
```

- 分层总览：命局层/事占层/时空层各自分数与断语；引擎综合分仅参考，不跨层平均
- 各术明细：按层分组，图标、名称、分数、趋势、摘要、断语、关键提示、**事域关联**（用 `DomainAnalysis` 按所问之事二次解读）
- 事域交叉：看好/平稳/谨慎计数 + 各术洞察 + 共识文本（态度汇总）
- 层内融洽：只在同层两两比较，不做跨层融洽度
- 融合研判：分层结论 + 命事互证（命局支持/时机未到/借势速决等）+ 行动建议；引擎原始综合文本折叠保留
- 评分确定性：`composite-engine` 去除 `Math.random`，优先用引擎 score/五行平衡分/等级映射，缺失时用内容哈希稳定兜底
- 主站 `components/composite.js` 同步限制最多 3 门
- 若部分引擎返回空结果，显式提示「X 门术数无有效结果」，不静默降级
