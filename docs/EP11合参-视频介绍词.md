# 天机阁 EP11 合参 · 视频介绍词

## 一、口播稿（连续版）

欢迎回到天机阁。前面十期，我们一门一门讲了风水、八字、六爻、梅花、奇门、太乙、诸葛神数、紫微斗数、大六壬、周公解梦。

每门术数都有自己的角度：八字看长期底色，六爻看当下事机，梅花看卦象变化，奇门看时空格局。可现实里的一个问题，往往一门说不透。

这期讲合参：最多同时选三门术数，并行推演同一个问题。系统先按命局层、事占层、时空层分层，再在层内融合、跨层做命事互证，不把长期底色和当下事机混为一谈。

输入很简单。出生日期、时辰、性别，给八字和紫微排盘；占测日期和占时，给奇门、太乙、大六壬起局；再写下所问之事，也可以直接点事业、感情、财运这些标签，系统会自动识别事域。

合参模式有四种：命事合参、命局合参、事占合参、自定义。最多三门，超过会提示。

点开始推演。完成后先看到分层总览：命局层、事占层、时空层各自给分和断语，综合分只作参考，不跨层平均。

往下是各术推演。这张卡最值得看：每一门术数的分数下面，都写了评分依据。八字是五行平衡分，六爻是卦象评分，梅花是体用生克等级，奇门是三吉门数量。分数怎么来的，一眼能对上。

再点开「展开完整盘面」，就不是只有一句结论了。八字能看到四柱干支和纳音，六爻能看到六亲、纳甲、世应和动爻，梅花有本卦互卦变卦和体用类象，奇门是完整的九宫格，紫微是十二宫加四化，大六壬有四课三传和天地盘。每一门都按它自己的规矩摊开给你看。

再往下是事域交叉，统计几门看好、几门谨慎，给出共识；层内融洽只在同一层里两两比对；最后是命事互证——长期底色和当下事机是同向还是错位，直接给结论和行动建议。

推演完可以点「保存卦例」。下次复盘直接载入存档，不重新起盘，所以不会换盘。

需要说明：多术数合参属于中国传统文化与术数文化遗产范畴。本系统仅供文化研究和娱乐参考，不构成任何人生决策建议。请相信科学，理性看待命运。

体验地址在视频下方简介。关注天机阁，继续探索中国传统术数的奥秘。

## 三、录制提示

- 默认命事合参（八字、六爻、梅花）即可，出生日期换成真实案例。
- 演示「评分依据」时停在六爻或梅花，一句话就能说清。
- 「展开完整盘面」只展开六爻和奇门各一次，八字详情很长，全展开会占好几屏。
- 六爻是实时盘，重算会换盘，演示一次就够。
- 解梦若选，梦境用常见意象（水、蛇、龙、考试、掉牙）。
- 卦例盒录制前先清空，保证空态开场。
