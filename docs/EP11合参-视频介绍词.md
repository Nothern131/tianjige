# 天机阁 EP11 合参 · 视频介绍词

---

欢迎回到天机阁。今天我们来讲解的是「合参」系统——多术数融合研判。

前面十期，我们分别讲了风水、八字、六爻、梅花、奇门、太乙、诸葛神数、紫微斗数、大六壬、周公解梦。每一门术数都有自己看世界的角度：八字看命局，六爻看事机，梅花看卦象，奇门看时空，太乙看大势，紫微看星盘，六壬看课传，解梦看潜意识。可现实里的一个问题，往往不是一门术数就能说透的。

合参系统，就是把它们放在一起看。你最多可以同时选择九门术数，让它们并行推演同一个问题，再由融合算法把各自的结果归一化、加权、交叉，最后给出一个统一的研判。

输入很简单：出生日期、时辰、性别，供八字和紫微排盘；占测日期与占时，供奇门、太乙、大六壬起局；再写下你所问之事，系统会自动识别它属于事业、感情、财运、健康、学业、家庭、人际还是出行。

推演完成后，你会看到六层结果。第一层是综合评分，用 0 到 100 分、五星与趋势，给出多术数加权后的总体判断。第二层是各术独立推演，每一门术数都有自己的分数、断语和关键提示，谁乐观、谁谨慎，一目了然。

第三层是事域交叉分析，系统会统计有多少门术数看好、多少门趋于平稳、多少门持谨慎态度，并给出针对你所问之事的共识判断。第四层是融洽磨合：两两比对术数之间的结论差异，算出融洽度与磨合度，告诉你哪些组合高度一致，哪些组合需要分开解读。

第五层是融合研判，把各术结论、事域共识、分歧点整合成一份完整的报告，并给出近期、中期、远期的三阶段推演。最后还有置信度与分歧跨度，让你知道这份合参结论到底有多稳。
