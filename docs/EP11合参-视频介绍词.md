# 天机阁 EP11 合参 · 视频介绍词

---

欢迎回到天机阁。今天我们来讲解的是「合参」系统——多术数融合研判。

前面十期，我们分别讲了风水、八字、六爻、梅花、奇门、太乙、诸葛神数、紫微斗数、大六壬、周公解梦。每一门术数都有自己看世界的角度：八字看命局，六爻看事机，梅花看卦象，奇门看时空，太乙看大势，紫微看星盘，六壬看课传，解梦看潜意识。可现实里的一个问题，往往不是一门术数就能说透的。

合参系统，就是把它们放在一起看。你最多可以同时选择三门术数，让它们并行推演同一个问题；系统先按命局层、事占层、时空层分组，再在层内融合、跨层做命事互证，避免把长期底色和当下事机混为一谈。

输入很简单：出生日期、时辰、性别，供八字和紫微排盘；占测日期与占时，供奇门、太乙、大六壬起局；再写下你所问之事，系统会自动识别它属于事业、感情、财运、健康、学业、家庭、人际还是出行。

推演完成后，你会看到六个区块。第一个是分层总览：命局层、事占层、时空层各自给出分数与断语，引擎综合分只作参考，不跨层平均。第二个是分层各术推演：每门术数按层分组，给出分数、断语、关键提示，以及针对你所问之事的「事域关联」原文。

第三个是事域交叉分析，统计看好、平稳、谨慎的门数与共识，作为态度汇总。第四个是层内融洽磨合：只在同一层内两两比对，不再把命局和事占混在一起算分歧。

第五个是融合研判：先给命局层、事占层、时空层的分层结论，再做命事互证——长期底色与当下事机是同向还是错位，最后给出行动建议。引擎原始综合文本折叠保留，供参考。
