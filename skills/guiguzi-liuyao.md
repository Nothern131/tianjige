# 鬼谷子六爻纳甲筮法

> 捭阖者，天地之道。捭阖者，以变动阴阳，四时开闭，以化万物。
> ——《鬼谷子·捭阖第一》

---

## 一、Scope（范围界定）

本技能聚焦于**六爻纳甲筮法的学习与研究**，非宣扬迷信。六爻纳甲筮法是中国古代预测学的重要分支，
其理论根基可追溯至战国鬼谷子（王诩）的阴阳五行思想，由西汉京房（京君明）集大成，纳天干地支于卦爻，
创"纳甲筮法"，遂成后世六爻占卜之正统。

### 学习目标

1. 掌握铜钱起卦之法，理解天人感应之理
2. 精通纳甲装卦，知晓天干地支与卦爻之配
3. 明辨世应二爻，界定人我主客
4. 熟稔六亲生克，洞察事物因果
5. 通晓六兽安布，参详吉凶辅助
6. 学会用神取用，直指所占之事

### 不适用范围

- 不用于医疗诊断、法律诉讼等专业领域决策
- 不替代理性分析与科学判断
- 不为赌博、投机等提供所谓"天机"

## 二、Workflow（工作流程）

六爻筮法，其要有五：起卦以通神明，纳甲以定干支，世应以别人我，六亲以明生克，六兽以参吉凶，
终而断卦以决嫌疑。五步环环相扣，缺一不可。

```
铜钱起卦 → 纳甲装卦 → 世应定位 → 六亲六兽 → 断卦研判
   │           │           │           │           │
   ▼           ▼           ▼           ▼           ▼
 得卦象     配干支      定主客     明关系     出结论
 识动变     安六亲      分人我     参六兽     辨吉凶
```

### 第一步：铜钱起卦

**法器**：铜钱三枚（乾隆通宝为佳），竹筒或龟壳一具。

**仪轨**：
1. 净手焚香，静心凝神，默念所占之事
2. 三枚铜钱置于掌心，双手合十，摇动后掷于案上
3. 共摇六次，自下而上记录爻象，初爻在下，上爻在上

**爻象判定**（以有字一面为阴/背，无字一面为阳/面）：
- 一背二面：少阳 ▅▅▅▅▅（阳爻，记作 `—` 或 `⚊`）
- 二背一面：少阴 ▅▅ ▅▅（阴爻，记作 `- -` 或 `⚋`）
- 三背皆背：老阳 ▅▅▅▅▅○（阳爻动变阴，记作 `—○`）
- 三面皆面：老阴 ▅▅ ▅▅×（阴爻动变阳，记作 `- -×`）

**老少之辨**：老阳数九，老阴数六；少阳数七，少阴数八。老变少不变，动爻为变，静爻不变。

### 第二步：纳甲装卦

以所得卦象，按纳甲歌诀，配天干地支于六爻。

**八宫卦序**（京房八宫卦次）：
乾宫八卦为首，次坎、艮、震、巽、离、坤、兑，各领八卦，共六十四卦。

**纳甲歌诀**（见知识章），每爻各配一干支，初爻起地支，隔位顺排。

### 第三步：世应定位

按八宫卦次定世爻、应爻之位。世为我，应为彼。世应相隔二爻（即世爻与应爻之间隔两爻）。

**世爻口诀**：
> 八卦之首世六当，以下初爻轮上扬。
> 游魂之卦四爻立，归魂之卦三爻详。

每宫八卦，世爻依次在：上爻（六世）、初爻（一世）、二爻（二世）、三爻（三世）、四爻（四世）、五爻（五世）、四爻（游魂）、三爻（归魂）。

### 第四步：六亲六兽

**安六亲**：以卦宫所属五行为"我"，按生克关系定六亲于各爻。

**安六兽**：以起卦日之天干为据，按"甲乙起青龙"之序，自初爻向上顺排六兽。

### 第五步：断卦

取用神、观生克、审动变、参日月、辨旺衰，综合诸因素下断语。

### 3.3 六亲生克

#### 3.3.1 六亲定义

以卦宫所属五行（即"我"）为基准：

| 关系 | 六亲 | 含义 |
|------|------|------|
| 同我者 | 兄弟 | 比肩、竞争、朋友、破财 |
| 我生者 | 子孙 | 福神、财源、医药、晚辈 |
| 我克者 | 妻财 | 财帛、妻妾、食物、利益 |
| 克我者 | 官鬼 | 官非、疾病、功名、丈夫 |
| 生我者 | 父母 | 文书、长辈、房屋、庇护 |

#### 3.3.2 六亲生克歌诀

```
生我者为父母，我生者为子孙。
克我者为官鬼，我克者为妻财。
同我者为兄弟，比肩劫财之分。
```

#### 3.3.3 用神取用与六亲对应

| 所占之事 | 取用神 | 说明 |
|----------|--------|------|
| 功名、考试、官运 | 官鬼 | 官鬼为功名之神 |
| 财运、生意、求财 | 妻财 | 妻财为财帛之神 |
| 疾病、医药、子女 | 子孙 | 子孙为福神，克官鬼 |
| 文书、契约、长辈 | 父母 | 父母为文书之神 |
| 婚姻、感情 | 官鬼（女）/ 妻财（男） | 女占夫以官鬼为用，男占妻以妻财为用 |
| 竞争、合作、手足 | 兄弟 | 兄弟有帮扶之力，亦有破财之患 |
| 出行、行人、安危 | 世爻 | 世为我身，出行看世爻旺衰 |
| 天气、年运 | 六亲综合 | 父母为雨，子孙为晴，妻财为晴，官鬼为雷电 |

#### 3.3.4 六亲生克关系

```
相生：父母生兄弟 → 兄弟生子孙 → 子孙生妻财 → 妻财生官鬼 → 官鬼生父母
相克：父母克子孙 → 子孙克官鬼 → 官鬼克兄弟 → 兄弟克妻财 → 妻财克父母
```

**生克要义**：
- 用神得生则吉，用神受克则凶
- 原神生用神者为吉，忌神克用神者为凶
- 仇神克原神，间接害用神
- 闲神不直接参与生克，但可借势发力

#### 3.4.2 六兽含义详释

**青龙**（木·东方）：
- 主吉庆、喜事、酒色、财帛
- 临用神：喜事临门，贵人相助
- 临忌神：酒色之灾，乐极生悲
- 性格：正直、仁慈、有威仪

**朱雀**（火·南方）：
- 主口舌、文书、是非、消息
- 临用神：文书有成，消息灵通
- 临忌神：口舌是非，官司缠身
- 性格：善辩、急躁、多言

**勾陈**（土·中央）：
- 主田土、房产、牵连、迟滞
- 临用神：田产有成，根基稳固
- 临忌神：牵连拖累，事情迟滞
- 性格：稳重、固执、保守

**螣蛇**（又称腾蛇，土·变）：
- 主虚惊、怪异、梦寐、疑虑
- 临用神：灵感忽至，变化之机
- 临忌神：虚惊一场，心神不宁
- 性格：多疑、善变、敏感

**白虎**（金·西方）：
- 主血光、丧事、疾病、凶暴
- 临用神：果断刚毅，雷厉风行
- 临忌神：血光之灾，疾病缠身
- 性格：刚猛、果断、威严

**玄武**（水·北方）：
- 主盗贼、暗昧、隐私、水厄
- 临用神：暗中得利，智谋有成
- 临忌神：贼盗之患，暗中受损
- 性格：机智、隐秘、深沉

### 3.5 世应关系

#### 3.5.1 世应定位法则

世爻为我，应爻为彼。世应相隔二爻，即世爻与应爻之间隔两个爻位。

**八宫世爻定位口诀**：
```
八卦之首世六当，一世初爻二世二。
三世在三四在四，五世在五各相当。
游魂四爻归魂三，世应相隔二爻详。
```

**详解**：

| 卦类 | 世爻位置 | 应爻位置 |
|------|----------|----------|
| 八纯卦（本宫） | 上爻（六爻） | 三爻 |
| 一世卦 | 初爻 | 四爻 |
| 二世卦 | 二爻 | 五爻 |
| 三世卦 | 三爻 | 上爻 |
| 四世卦 | 四爻 | 初爻 |
| 五世卦 | 五爻 | 二爻 |
| 游魂卦 | 四爻 | 初爻 |
| 归魂卦 | 三爻 | 上爻 |

#### 3.5.2 世应生克要义

- **世克应**：我制彼，事由我主，主动有利
- **应克世**：彼制我，事不由己，被动不利
- **世生应**：我生彼，我损己利人，付出多
- **应生世**：彼生我，人助我，得利
- **世应比和**：人我相合，两相情愿，事易成

### 3.6 用神取用精要

#### 3.6.1 用神吉凶判断

**用神旺相**：得日月生扶、动爻相生、临青龙吉神 → 所占之事可成
**用神休囚**：受日月克制、动爻相克、临白虎凶神 → 所占之事难成

**用神为空亡**：甲子旬中戌亥空，甲戌旬中申酉空，甲申旬中午未空，甲午旬中辰巳空，甲辰旬中寅卯空，甲寅旬中子丑空。用神逢空，事多虚而不实。

**用神入墓**：木墓在未、火墓在戌、金墓在丑、水土墓在辰。用神入墓，如人入囚，有力难施。

#### 3.6.2 原神、忌神、仇神

- **原神**：生用神者，为用神之源。原神旺相则用神有根。
- **忌神**：克用神者，为用神之敌。忌神旺相则用神受损。
- **仇神**：克原神者，间接害用神。仇神动则断用神之源。

#### 3.6.3 月建日辰

- **月建**：当令之月支，司一月之权。爻值月建为旺，月建生之为相，月建克之为死。
- **日辰**：当日之日支，司一日之权。爻值日辰为旺，日辰生之为相，日辰克之为死。

## 四、Style（行文风格）

### 4.1 鬼谷子纵横捭阖风格

言辞当如鬼谷子，纵横捭阖，简而有力：
- **古文言简意赅**：用文言文风，少用白话长句，多用四字断语、五言口诀
- **捭阖之道**：吉中有凶，凶中有吉，不绝对化，留有余地
- **阴阳辩证**：万物负阴而抱阳，断卦时兼顾正反两面
- **类比取象**：以天地万物类比卦象，如"青龙在天，利见大人"、"白虎临门，谨防血光"

### 4.2 断语风格

```
吉断：青龙得位，贵人相助，所求遂意，诸事亨通。
凶断：白虎临爻，血光暗伏，谨慎行事，勿轻举妄动。
中平：勾陈守中，事缓则圆，不宜急进，静待时机。
```

### 4.3 输出格式

卦成之后，按以下格式输出：

```
【卦象】䷀乾为天（乾宫，八纯卦，六世卦）
【世应】世在六爻（上爻），应在三爻
【起卦日】甲子日（旬空：戌亥）

【六爻排盘】
初爻：甲子 父母 ── 青龙
二爻：甲寅 官鬼 ── 朱雀
三爻：甲辰 父母 ── 勾陈（应爻）
四爻：壬午 官鬼 ── 螣蛇
五爻：壬申 兄弟 ── 白虎
上爻：壬戌 父母 ── 玄武（世爻）

【用神】以[占事]取[用神]为用，在[某爻]
【断语】[吉凶断语，捭阖风格]
```

## 五、Safety（安全声明）

### 5.1 核心原则

> 占卜者，决嫌疑、定犹豫也。然天命靡常，惟德是辅。
> 占卜仅供参酌，不可执迷。重大决策，当以理性判断为本。

### 5.2 安全准则

1. **占卜仅供参酌**：卦象所示，乃天地气运之一端，非定命不可改。人之努力、德行、智慧，可转祸为福。
2. **重大决策需理性判断**：涉及医疗、法律、投资、婚姻等重大事项，必须以专业意见和理性分析为准，占卜仅为辅助参考。
3. **不制造恐慌**：遇凶卦不危言耸听，以"谨慎行事"、"静待时机"等建设性语言替代恐惧诱导。
4. **不保证结果**：卦象解读为概率性判断，不可承诺"一定应验"或"绝对准确"。
5. **尊重科学**：六爻筮法为传统文化遗产，有其文化价值与哲学智慧，但不替代现代科学。
6. **不涉及敏感领域**：拒绝预测他人死亡、重大灾难、国运政治等敏感事项。
7. **保护隐私**：占卜中涉及的个人信息严格保密，不记录、不传播。

### 5.3 免责声明模板

每次断卦后附：
> 以上断语，本于卦象爻辞，参以纳甲生克，仅供参酌。天行健，君子以自强不息；地势坤，君子以厚德载物。福祸无门，惟人自召。愿君以理性为舵，以智慧为帆，自求多福。
