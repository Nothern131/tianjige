# 王朴 · 太乙神数

## Scope（范围）

本 Skill 专注于太乙神数的学习、研究与推算，涵盖以下领域：

1. **太乙积年**：理解太乙积年的天文历算基础，掌握积年推算方法
2. **太乙行宫**：掌握太乙在九宫（十二宫）中的运行规律，每三年移一宫，二十四年一周
3. **十六神体系**：精通十六神（地主、阳德、和德、吕申、高丛、太阳、大炅、大神、大威、天道、大武、武德、太簇、阴主、阴德、大义）的定位与吉凶判断
4. **五福三基**：掌握君基、臣基、民基、五福、大游的推算方法
5. **计神始击**：掌握计神、始击、文昌、主大将、客大将的定位与作用
6. **四神十二宫**：理解四神（太乙、文昌、始击、计神）与十二宫的关系
7. **断局思维**：培养宏观预测的思维框架——天时、地利、人和、神助四维分析

**核心原则**：太乙神数不是占卜个人吉凶的工具，而是推演国运、洞察天时的宏观预测学。学习者需具备敬畏之心，不可妄用。

## Workflow（推算流程）

太乙神数完整推算流程分为六个步骤，由宏观到微观，层层递进：

### 第一步：定太乙积年

**目的**：确定当前年份的太乙积年数，为后续所有推算建立时间基准。

**算法**：
```
太乙积年 = 10153937 + 当前公历年份
```

**说明**：
- 太乙积年起始于上古"上元甲子"，以公元前 10153937 年为积年起点
- 实际推算中，常以公元 1900 年为简化基准（积年 = 10155837）
- 积年数用于计算太乙在周期中的位置

**输出**：
- 太乙积年数
- 入纪元数（72 年一纪，积年 ÷ 72 取整）
- 入纪年数（积年 mod 72，若余 0 则为 72）

### 第二步：推算太乙位置

**目的**：确定太乙在九宫中的位置，判断太乙值何种十六神。

**太乙行宫规则**：
- 太乙巡行九宫，每三年移一宫
- 二十四年走完一周（3 × 8 = 24，中宫不计）

**推算方法**：
```
太乙宫位序号 = 太乙积年 mod 24
若余数为 0，则宫位序号为 24
```

**主大将与客大将**：
- 主大将代表我方（本国）军事力量
- 客大将代表敌方（外敌）军事力量
- 主大将旺相而客大将衰囚：我强敌弱，可战
- 客大将旺相而主大将衰囚：敌强我弱，宜守
- 主客二将同宫或相合：和谈有望

**三、人和维度（三基 + 文昌）**：
- 君基：帝王气运，国家领导力

- 民基：百姓民生，社会稳定

**四、神助维度（五福 + 大游）**：

**断局综合判断**：
- 四维皆吉 → 国泰民安，风调雨顺
- 三维吉一维凶 → 虽有不足，大局稳定
- 二维吉二维凶 → 吉凶参半，需谨慎应对

## Knowledge（知识体系）

### 一、太乙积年算法详解

**上元甲子**：
太乙神数以太乙积年为根本，积年起算于"上元甲子"——即日月合璧、五星连珠之时。据古籍记载，上元甲子距今约 10153937 年（以公元 0 年计）。

**积年公式**：
```
太乙积年 = 10153937 + 年份（公元）
```

**简化基准**（与天机阁代码一致）：
```
基准年：公元 1900 年
基准积年：10155837
太乙积年 = 10155837 + (年份 - 1900)
```

**周期体系**：
- 72 年为一纪（太乙运行周期）
- 24 年为一周（太乙行宫一周）
- 3 年移一宫（太乙每宫停留时间）

**阳遁与阴遁**：
- 太乙积年奇数为阳遁，偶数为阴遁
- 阳遁：太乙顺行（乾→午→艮→卯→子→酉→坤→戌→巽→辰→亥→巳）
- 阴遁：太乙逆行（巳→亥→辰→巽→戌→坤→酉→子→卯→艮→午→乾）

### 三、五福三基详解

**五福**为太乙神数中判断福禄的五种神煞，各有运行周期：

| 神煞 | 周期 | 吉凶 | 主事 |
|------|------|------|------|
| 君基 | 30 年 | 吉 | 帝王气运，国家根本 |
| 臣基 | 3 年 | 吉 | 臣子气运，官员仕途 |
| 民基 | 1 年 | 吉 | 百姓民生，民间气运 |
| 五福 | 45 年 | 大吉 | 福禄吉祥，国泰民安 |
| 大游 | 36 年 | 凶 | 灾祥变化，天象异变 |

**三基**（君基、臣基、民基）为五福中的前三者，合称"三基"，是判断国运上中下三层的基础：

- **君基**（上）：主国家领导层面，帝王气运、中央决策
- **臣基**（中）：主官员行政层面，政策执行、官僚体系
- **民基**（下）：主百姓民生层面，社会安定、生活水平

**三基关系**：
- 君基得位而臣基不得位 → 上有明君，下无良臣，政令难行
- 臣基得位而君基不得位 → 下有良臣，上无明君，才能难施
- 民基得位而君基、臣基不得位 → 百姓自安，但治理不力
- 三基皆得位 → 上下一心，国泰民安（极罕见）

### 四、四神十二宫

**四神**是太乙神数中最重要的四位神煞：
1. **太乙**：主神，代表天时、天命
2. **文昌**：文运之神，主文化、教育
3. **始击**：武运之神，主军事、征伐
4. **计神**：谋略之神，主决策、谋划

**十二宫**（地支）：
- 子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥
- 含四维：乾（西北）、坤（西南）、艮（东北）、巽（东南）

**四神在十二宫的关系**：
- 太乙与文昌同宫：文治昌明
- 太乙与始击同宫：武功强盛
- 太乙与计神同宫：谋划得当
- 文昌与始击同宫：文武兼备
- 计神与始击相冲：谋划与军事冲突
- 四神会合（同宫或三合）：大吉，但千年难遇

**四神十二宫吉凶总诀**：
```
太乙文昌同宫吉，文运昌盛国安宁。
太乙始击同宫利，武功强盛四海平。
太乙计神同宫善，谋划得当万事成。
文昌始击不同宫，文武相济为佳境。
四神分散各一方，宜守不宜妄出征。
```

### 五、太乙行宫

太乙在九宫（实际为十二宫含四维）中巡行，每三年移一宫，二十四年走完一周。

**行宫次序（阳遁顺行）**：

### 六、王朴的学术贡献

**王朴（906-959）**，字文伯，五代时期后周大臣、天文学家、数学家。
