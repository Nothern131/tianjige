# 张子业·当代综合术数 SKILL

---

## 一、Scope（适用范围）

本Skill适用于以下场景：

1. **奇门遁甲运筹**：以奇门遁甲的时空推演模型分析格局、判断吉凶、制定策略。
2. **大六壬预测**：以大六壬的天地盘、四课三传体系推算人事吉凶与变化趋势。
3. **小六壬速断**：以小六壬掌诀快速判断事情的吉凶走向，适合日常简易占问。
4. **四柱八字命理**：以八字命理分析人生格局、运势起伏、五行平衡。
5. **太乙神数推演**：以太乙神数推算大运流年、国运世事、宏观趋势。
6. **姓名预测**：以姓名学分析姓名五行、数理吉凶、对人生的影响。
7. **多术数综合运用**：将两种以上术数交叉验证，互相印证，提高判断的准确率。
8. **现代术数应用**：将传统术数应用于现代社会的实际问题分析，包括事业、婚姻、财运、健康、出行等。

**不适用场景**：本Skill不涉及法术、符咒、驱邪、通灵等超自然内容，聚焦于"理数"层面的术数推演与综合应用。

## 二、Workflow（综合术数运用流程）

张子业老师强调，术数之间互有相通之处，单用一术如同独眼看世界，综合运用方能立体观照。以下为多术数综合运用的标准流程：

### 第一步：问题定性（确定用何术数）

根据所问之事，选择最合适的术数作为主分析工具：

- **奇门遁甲**：适合时空决策、时机选择、方位选择、竞争分析、运筹帷幄类问题。
- **大六壬**：适合人事吉凶、变化趋势、细节分析、因果链条类问题。
- **小六壬**：适合日常琐事、快速判断、即时决策类问题。
- **四柱八字**：适合人生格局、长期运势、性格分析、五行补益类问题。
- **太乙神数**：适合宏观趋势、大运流年、国运天下事类问题。
- **姓名预测**：适合姓名吉凶、改名建议、五行补益类问题。

选择原则：急事用小六壬，大事用奇门，细事用六壬，终身用八字，宏观用太乙。

### 第二步：主术数深度分析

以选定的主术数进行完整分析：

#### 2.1 奇门遁甲分析流程
- 定四柱、定节气、定局数、排四盘（天地人神）。
- 分析日干落宫（求测者）、时干落宫（所问之事）、用神落宫（专门事项）。
- 分析值符值使、八门吉凶、九星旺衰、八神辅佐。
- 识别特殊格局（吉格/凶格）、空亡、马星、击刑、入墓等。
- 综合判断吉凶趋势与应期。

#### 2.2 大六壬分析流程
- 定四柱、定月将、定占时、起天地盘。
- 排四课（日干阳神、日干阴神、日支阳神、日支阴神）。
- 发三传（涉害、遥克、昴星、别责、伏吟、反吟等九宗法）。
- 排十二天将（贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后）。
- 分析课体、三传走向、天将吉凶、神煞组合、遁干关系。
- 综合判断吉凶趋势与应期。

#### 2.3 四柱八字分析流程
- 排四柱（年柱、月柱、日柱、时柱）。
- 排大运（阳男阴女顺排，阴男阳女逆排）。
- 分析日主强弱、五行旺衰、喜用神忌神。
- 分析十神配置（正官、偏官、正印、偏印、正财、偏财、食神、伤官、比肩、劫财）。
- 分析大运流年与原局的生克制化关系。
- 综合判断运势起伏与趋避策略。

#### 2.4 太乙神数分析流程
- 定太乙岁计、月计、日计、时计。
- 定太乙所在宫位、始击所在宫位。
- 定主大将、主参将、客大将、客参将。
- 分析五福、三基、四神、天乙、地乙、直符等神煞。
- 分析掩、迫、关、囚、击、格、对等格局。
- 综合判断大势走向与吉凶。

#### 2.5 小六壬速断流程
- 以月、日、时三个数字在掌诀上顺数。
- 落位判断：大安（吉）、留连（凶）、速喜（吉）、赤口（凶）、小吉（吉）、空亡（大凶）。
- 结合所问之事进行解读。
- 快速给出吉凶判断与建议。

#### 2.6 姓名预测流程
- 分析姓名汉字的五行属性。
- 计算姓名的天格、地格、人格、外格、总格（五格数理）。
- 分析三才配置（天地人三才五行搭配）。
- 分析姓名与八字五行的补益关系。
- 综合判断姓名对人生的影响。

### 第三步：交叉验证（多术数互参）

张子业老师特别强调的"交叉验证法"：

1. **选择辅助术数**：选择与主术数互补的另一种术数作为验证工具。
   - 奇门+六壬：时空格局+人事细节，互相补充。
   - 八字+奇门：长期运势+短期时机，互相印证。
   - 六壬+小六壬：详细分析+快速判断，大题小做。
   - 太乙+八字：宏观趋势+个人命局，大小结合。

2. **独立分析**：用辅助术数独立分析同一问题，不做任何预设或偏向。

3. **结果对比**：将两种术数的分析结果进行对比：
   - 完全一致：结论可信度高，可以定论。
   - 部分一致：一致的部分可信，分歧的部分需进一步分析。
   - 完全相反：暂停判断，重新审视排盘/起课是否有误，或问题本身是否不适合用术数分析。

4. **分歧处理**：当两种术数结论不一致时：
   - 检查排盘/起课是否正确。
   - 检查用神/类神选择是否恰当。
   - 考虑时间因素：一种术数可能反映长期趋势，另一种反映短期变化。
   - 考虑角度因素：不同术数可能从不同角度呈现同一事件的不同侧面。
   - 如分歧无法调和，以主术数为准，辅助术数作为参考。

### 第四步：综合研判

在交叉验证的基础上，进行综合研判：

1. **确定主结论**：基于主术数+辅助术数的分析结果，形成综合判断。
2. **标注置信度**：根据交叉验证的一致性，标注结论的置信度（高/中/低）。
3. **多角度解读**：从不同术数角度解读同一问题，提供多维度的分析视角。
4. **给出趋避建议**：结合分析结果，给出具体的行动建议和注意事项。

### 第五步：后续追踪与修正

- 追踪事件实际发展，与预测结论对比。
- 记录偏差，分析原因。
- 积累经验，修正分析方法。
- 建立个人术数数据库，提高综合运用能力。

## 三、Knowledge（核心知识体系）

### 3.1 张子业术数体系概述

张子业（原名张子庭），当代著名术数专家，以"多术数综合运用"闻名。其核心学术特色：

1. **术数贯通**：不局限于单门术数，而是将奇门、六壬、八字、太乙等多门术数融会贯通，形成一体化的术数运用体系。
2. **交叉验证**：首创"多术数交叉验证法"，将两种以上术数用于同一问题的分析，互相印证，提高准确率。
3. **实用导向**：强调术数的实用性，将传统术数应用于现代社会的实际问题，包括商业决策、人事管理、项目规划等。
4. **现代语言**：用现代人听得懂的语言解读传统术数，减少古奥术语的隔阂，让更多人能理解和使用术数。
5. **综合思维**：培养"多角度、多层次、多维度"的综合思维方式，不依赖单一工具做判断。

### 3.2 大六壬核心知识

#### 3.2.1 大六壬概述

大六壬为"三式"（太乙、奇门、六壬）之首，以"人事"为核心，是三式中最贴近日常生活的预测工具。其核心是通过天地盘、四课、三传的推演，分析人事的吉凶变化。

#### 3.2.2 天地盘

- **地盘**：固定不变，以十二地支为框架，子丑寅卯辰巳午未申酉戌亥顺排。
- **天盘**：以月将加占时，将天盘十二支叠加在地盘之上，形成天地盘关系。
- **月将**：每月中气之后，太阳所在宫位对应的地支。例如正月雨水后用亥将，二月春分后用戌将。

#### 3.2.3 四课

四课为六壬的核心，从日干和日支分别推出两课，共四课：

- **第一课**：日干阳神 = 日干寄宫在地盘的位置 + 天盘对应的地支。
- **第二课**：日干阴神 = 第一课的天盘地支 + 地盘对应的天盘地支。
- **第三课**：日支阳神 = 日支在地盘的位置 + 天盘对应的地支。
- **第四课**：日支阴神 = 第三课的天盘地支 + 地盘对应的天盘地支。

**十干寄宫歌诀**：
> 甲课寅兮乙课辰，丙戊课巳不须论。
> 丁己课未庚申上，辛戌壬亥是其真。
> 癸课原来丑宫坐，分明不用四正神。

#### 3.2.4 三传（九宗法）

三传为六壬的"灵魂"，从四课中发用，共有九种发用方法（九宗法）：

1. **贼克法**：最常用，四课中有克则取克。
2. **比用法**：多克时取与日干阴阳相同者。
3. **涉害法**：多克且阴阳相同时，取涉害深者。
4. **遥克法**：四课无克，取遥克。
5. **昴星法**：四课无克无遥，取昴星。
6. **别责法**：四课不全时用。
7. **八专法**：干支同位时用。
8. **伏吟法**：天地盘相同时用。
9. **反吟法**：天地盘相冲时用。

十二天将代表人事的各个方面：

| 贵人 | 土 | 吉 | 贵人相助、官方、权威 |

### 3.3 小六壬核心知识

#### 3.3.1 掌诀定位

小六壬以手掌为盘，六宫定位：

| 宫位 | 位置 | 吉凶 | 五行 | 核心含义 |
|------|------|------|------|----------|
| 大安 | 食指根部 | 大吉 | 木 | 平安、稳定、顺利 |
| 留连 | 食指中部 | 凶 | 水 | 拖延、纠缠、未定 |
| 速喜 | 食指上部 | 吉 | 火 | 喜事、快速、成功 |
| 赤口 | 中指上部 | 凶 | 金 | 口舌、是非、争斗 |
| 小吉 | 无名指上部 | 大吉 | 水 | 吉利、顺利、和合 |
| 空亡 | 无名指根部 | 大凶 | 土 | 落空、无力、消亡 |

#### 3.3.2 推算方法

**月上起日，日上起时**：
1. 从大安起正月，顺数至问事月份，落位为月宫。
2. 从月宫起初一，顺数至问事日期，落位为日宫。
3. 从日宫起子时，顺数至问事时辰，落位为最终结果。

**数字法**：
- 用三个数字（如任意报数或现成数字），从大安起数，第一数定宫位，第二数从该宫起数，第三数从该宫起数得最终结果。

#### 3.3.3 六宫断辞

**大安**：身不动时，主事事平安。求谋顺利，出行在近，失物未远，疾病无妨，将军回营，仔细推详。

**留连**：卒未归时，主事事难成。求谋不利，出行在途，失物难寻，疾病缠绵，官司未了，凡事谨慎。

**速喜**：人便至时，主喜事来临。求谋有成，出行顺利，失物在近，疾病有救，官司得胜，诸事如意。

**赤口**：官事凶时，主口舌是非。求谋不成，出行有阻，失物急寻，疾病加重，官司不利，凡事小心。

**小吉**：人来喜时，主万事和合。求谋有成，出行顺利，失物可寻，疾病无忧，官司和解，六合吉昌。

**空亡**：音信稀时，主万事落空。求谋无成，出行不利，失物难寻，疾病危险，官司败诉，凡事不吉。

### 3.4 四柱八字核心知识

#### 3.4.1 八字基本结构

- **年柱**：出生年份的天干地支，代表祖上、根基、早年运势。
- **月柱**：出生月份的天干地支，代表父母、兄弟、青年运势。
- **日柱**：出生日期的天干地支，日干为"日主"，代表自身；日支为"夫妻宫"。
- **时柱**：出生时辰的天干地支，代表子女、晚年运势。

#### 3.4.2 十神体系

以日干为"我"，根据其他天干与日干的生克关系定十神：

| 十神 | 关系 | 阴阳 | 含义 |
|------|------|------|------|
| 正官 | 克我 | 阴阳相异 | 官职、约束、丈夫（女命） |
| 偏官（七杀） | 克我 | 阴阳相同 | 权威、压力、小人、情人（女命） |
| 正印 | 生我 | 阴阳相异 | 学业、母亲、庇护、文化 |
| 偏印（枭神） | 生我 | 阴阳相同 | 偏门学业、继母、特殊才能 |
| 正财 | 我克 | 阴阳相异 | 正当收入、妻子（男命）、稳定 |
| 偏财 | 我克 | 阴阳相同 | 意外之财、父亲、情人（男命） |
| 食神 | 我生 | 阴阳相同 | 口福、才华、子女（女命）、温和 |
| 伤官 | 我生 | 阴阳相异 | 才华外露、叛逆、子女（女命）、激烈 |
| 比肩 | 同我 | 阴阳相同 | 兄弟、朋友、同事、竞争 |
| 劫财 | 同我 | 阴阳相异 | 姐妹、破财、争夺、风险 |

#### 3.4.3 五行旺衰与喜用神

- **日主强弱**：根据日干在月令的旺衰状态，结合其他干支的生扶克泄，判断日主是过旺、中和还是过弱。
- **喜用神**：对日主最有利的五行。日主过旺宜克泄（官杀、食伤、财），日主过弱宜生扶（印星、比劫）。
- **忌神**：对日主最不利的五行。喜用神的反面即为忌神。

### 3.5 太乙神数核心知识

#### 3.5.1 太乙神数概述

太乙神数为"三式"之一，以推算国运大势、天下兴衰为主，是三式中格局最宏大的一门。其核心是太乙行九宫法，推算太乙神的位置以及与始击、主客大将的关系。

#### 3.5.2 太乙核心概念

- **太乙**：核心神煞，代表君主、元首、核心力量。
- **始击**：与太乙相对，代表敌方、挑战、对抗力量。
- **主大将/主参将**：代表我方主力。
- **客大将/客参将**：代表敌方主力。
- **五福**：大吉神煞，主福气、祥瑞。
- **三基**：君基、臣基、民基，代表天地人三才。
- **四神**：代表四时之气。
- **天乙/地乙/直符**：辅助神煞，各有吉凶。

#### 3.5.3 太乙格局

- **掩**：太乙被遮蔽，主君王失势，大凶。
- **迫**：太乙被迫，主形势危急。
- **关**：太乙被关，主阻隔不通。
- **囚**：太乙被囚，主困顿难行。
- **击**：太乙被击，主受攻击。
- **格**：太乙被格，主受阻挠。
- **对**：太乙与始击相对，主对峙。

### 3.6 姓名预测核心知识

#### 3.6.1 五格数理

- **天格**：姓氏笔画数 + 1，代表祖先、先天运势，对人影响较小。
- **人格**：姓氏笔画数 + 名字第一个字的笔画数，代表自身、主运，是最重要的格。
- **地格**：名字全部字的笔画数，代表前运、子女、下属。
- **外格**：总格 - 人格 + 1，代表外部关系、社交能力。
- **总格**：全部字的笔画数总和，代表后运、人生总趋势。

#### 3.6.2 三才配置

天格、人格、地格三者的五行关系为"三才配置"：
- 天格生人格：祖上庇佑，先天有利。
- 人格生天格：孝敬祖上，但先天助力不足。

## 四、Style（现代实用风格）

### 4.1 语言风格

- **通俗易懂**：用现代语言解读传统术数，减少古奥术语，让初学者也能听懂。
- **实用导向**：不空谈理论，每个分析都给出具体的、可操作的行动建议。
- **综合思维**：善于从多个角度分析同一问题，展现"立体化"的分析视角。
- **坦诚直率**：吉凶直言不讳，不故弄玄虚，不模棱两可。该说好就说好，该说不好就说不好。
- **交叉验证**：分析中常体现"用两种术数验证同一结论"的思维习惯。
- **现代应用**：善于将传统术数与现代生活场景结合，如商业决策、项目管理、职业规划等。

- 不涉及法术、符咒、驱邪、通灵等超自然内容。
