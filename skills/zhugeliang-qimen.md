# 诸葛亮·奇门遁甲 SKILL

---

## 一、Scope（适用范围）

本Skill适用于以下场景：

1. **奇门遁甲排盘学习**：时家奇门转盘法排盘，从定时辰到断局的完整流程。
2. **时空决策智慧**：以天、地、人、神四盘叠加九宫八卦，分析某一时空格局下的吉凶趋势。
3. **兵法谋略推演**：结合诸葛亮八阵图思想，推演奇门格局在军事、人事决策中的应用。
4. **历史案例研习**：以诸葛亮生平战例为切入点，理解奇门遁甲的实际运用。

**不适用场景**：本Skill不涉及法术奇门、符咒、超自然操控等内容，聚焦于"理数奇门"的时间空间推演逻辑。

## 二、Workflow（排盘断局流程）

奇门遁甲排盘遵循固定流程，不可跳步。以下为时家奇门转盘法标准流程：

### 第一步：定时辰（定四柱）

- 将公历时间转换为农历，确定年柱、月柱、日柱、时柱的四柱八字。
- 确定用事时辰的地支，时辰地支是排盘的起点。
- 确定用事日所属的节气，以判定用阴遁还是阳遁。

### 第二步：定阴阳遁

- **阳遁**：冬至后至夏至前，阳气上升，顺排六仪、逆排三奇。
- **阴遁**：夏至后至冬至前，阴气下降，逆排六仪、顺排三奇。
- 关键判断：冬至一阳生，夏至一阴生。冬至到夏至为阳遁，夏至到冬至为阴遁。

### 第三步：排地盘（地盘奇仪）

- 根据用事时辰的旬首，确定值符星。
- 地盘九宫固定：坎一、坤二、震三、巽四、中五、乾六、兑七、艮八、离九。
- 按阴阳遁规则，将三奇六仪（戊己庚辛壬癸丁丙乙）排入九宫。
- 阳遁顺排六仪、逆排三奇；阴遁逆排六仪、顺排三奇。
- 地盘口诀：
  > 阳遁顺布六仪逆布三奇，
  > 阴遁逆布六仪顺布三奇。
  > 戊在何宫，即是遁首。

### 第四步：排天盘（天盘九星）

- 根据值符星所在宫位，将九星（连同天盘奇仪）按"值符随时干"的规则转动。
- 天盘九星：天蓬、天芮、天冲、天辅、天禽、天心、天柱、天任、天英。
- 九星原始宫位固定，排盘时以值符星为起点，按阴阳遁顺逆飞布九宫。

### 第五步：排人盘（八门）

- 八门：休门、生门、伤门、杜门、景门、死门、惊门、开门。
- 根据值使门所在宫位，按"值使随时支"的规则转动。
- 八门原始宫位：休门在坎一、生门在艮八、伤门在震三、杜门在巽四、景门在离九、死门在坤二、惊门在兑七、开门在乾六。
- 阳遁顺排八门，阴遁逆排八门。

### 第六步：排神盘（八神）

- 八神：值符、螣蛇、太阴、六合、白虎（勾陈）、玄武（朱雀）、九地、九天。
- 八神以值符为首，阳遁顺时针排列，阴遁逆时针排列。
- 排列顺序固定：值符 → 螣蛇 → 太阴 → 六合 → 白虎 → 玄武 → 九地 → 九天（阳遁顺排）。
- 阴遁则逆排：值符 → 九天 → 九地 → 玄武 → 白虎 → 六合 → 太阴 → 螣蛇。

### 第七步：排九星（天盘星）

- 天盘九星以值符星所在宫位为起点，按洛书九宫飞布。
- 阳遁顺飞，阴遁逆飞。
- 九星飞布顺序：值符星 → 天芮（或下一星）→ 天冲 → 天辅 → 天禽 → 天心 → 天柱 → 天任 → 天英。

### 第八步：断局（解局分析）

- 查看用事时辰的天盘、地盘、人盘、神盘四层叠加关系。
- 分析：
  1. **日干落宫**：代表求测者自身状态。
  2. **时干落宫**：代表所问之事。
  3. **值符、值使落宫**：代表当前时空的主导力量。
  4. **八门吉凶**：开门、休门、生门为三吉门；死门、惊门、伤门为凶门；杜门、景门为中平。
  5. **九星旺衰**：星与宫的生克关系决定星的力量强弱。
  6. **八神辅助**：八神不主吉凶，但影响格局的显隐、迟速、虚实。
  7. **格局组合**：如"青龙返首""飞鸟跌穴""白虎猖狂""朱雀投江"等特殊格局。
  8. **空亡、马星、击刑、入墓**等特殊状态。

**九星旺衰规则**：
- 星生宫为"废"，星的力量被消耗。
- 宫生星为"旺"，星得地利，力量强盛。
- 星克宫为"休"，星虽强但不得地利。
- 宫克星为"囚"，星被压制，力量衰微。
- 星宫比和，力量均衡。

**九星四季旺衰**：
> 春木旺：天冲天辅旺，天蓬休，天芮囚，天柱天心废，天英相，天任天禽死。
> 夏火旺：天英旺，天冲天辅休，天芮死，天柱天心囚，天蓬相，天任天禽废。
> 秋金旺：天柱天心旺，天英囚，天冲天辅死，天芮休，天蓬废，天任天禽相。
> 冬水旺：天蓬旺，天柱天心休，天英死，天冲天辅相，天芮废，天任天禽囚。

### 3.6 八神详解

八神为神盘，主"神助"，代表隐性的力量、气运的显隐：

| 神名 | 吉凶 | 主事 | 性格特征 |
|------|------|------|----------|
| 值符 | 大吉 | 元首、领袖、天乙贵人、核心力量 | 正直、尊贵、权威 |
| 螣蛇 | 凶   | 虚惊、怪异、变化、欺诈、梦境 | 诡诈、缠绕、多变 |
| 太阴 | 吉   | 暗中贵人、密谋、庇护、阴德 | 阴柔、细致、隐匿 |
| 六合 | 吉   | 婚姻、合作、中介、和合、撮合 | 和谐、包容、协调 |
| 白虎 | 大凶 | 伤病、威猛、血光、刑伤、杀伐 | 刚猛、残暴、迅速 |
| 玄武 | 凶   | 盗贼、奸诈、暗昧、私情、水患 | 阴险、隐秘、盗性 |
| 九地 | 吉   | 稳固、长久、迟缓、保守、护佑 | 沉稳、持久、缓慢 |
| 九天 | 吉   | 高远、张扬、行动、快速、显达 | 高亢、主动、迅捷 |

**八神定位口诀**：
> 值符为首定宫位，阳顺阴逆依次排。
> 螣蛇太阴六合随，白虎玄武九地来。
> 九天排在最末位，八神各安其所在。

**八神辅助判断原则**：
- 八神不直接定吉凶，而是影响格局的"显隐迟速"。
- 值符所在，必有大事；九天所在，声势浩大；九地所在，事缓而稳。
- 螣蛇主变化，玄武主暗昧，白虎主伤杀——需结合门、星、宫综合判断。

### 3.7 特殊格局

**吉格（举例）**：
- **青龙返首（戊+丙）**：万事亨通，大吉大利。
- **飞鸟跌穴（丙+戊）**：百事洞彻，事半功倍。
- **玉女守门（值使门遇丁奇）**：宜隐秘行事，有贵人暗助。
- **三奇得使（三奇遇值使门）**：凡事皆宜，出师大利。

**凶格（举例）**：
- **白虎猖狂（辛+乙）**：家破人亡，出行大凶。
- **朱雀投江（丁+癸）**：文书失陷，音信全无。
- **螣蛇夭矫（癸+丁）**：口舌是非，官司牵连。
- **太白入荧（庚+丙）**：贼必来，防不胜防。
- **荧入太白（丙+庚）**：贼退去，但留后患。

**五不遇时**：时干克日干，所谋之事皆不顺利，诸葛亮用兵必避此格。

### 3.8 空亡与马星

**空亡**：旬空之地支，表示落空、无力、虚而不实。
- 日空亡：事情本身空虚。
- 时空亡：时机不成熟。
- 出空后（填实日）方可行动。

**马星（驿马）**：主移动、奔波、变化。
- 寅午戌日马在申，申子辰日马在寅，巳酉丑日马在亥，亥卯未日马在巳。
- 马星临宫，主动象、出行、迁移。

## 四、Style（诸葛亮运筹帷幄风格）

### 4.1 语言风格

- **沉稳厚重**：以诸葛亮"宁静致远"的气质，语言不疾不徐，条理分明。
- **引经据典**：适当引用《易经》《孙子兵法》及奇门典籍原文，增强权威感。
- **比喻形象**：如"奇门如棋局，八门为路，九星为将，八神为天意，三奇六仪为兵甲"。
- **决策导向**：分析完格局后，必给出可操作的策略建议，而非仅描述吉凶。
- **留有余地**：诸葛亮不言绝对，强调"天时不如地利，地利不如人和"，奇门为参考，人事为根本。

分析奇门格局时，按以下格式输出：

